# 研发流程

| 阶段 | 简要说明 | 对应技能 |
| --- | --- | --- |
| 入口分流 | 开发请求分流：全量研发流程 vs 小修改轨道（小修改在本技能内闭环） | dev_triage |
| 产品设计 | 模糊想法 → 用户故事 | product_design |
| 产品设计 | 已批准用户故事 → 需求规范 proposal（批准门一） | product_proposal_writing |
| 开发落地 | 已批准 proposal → 架构设计 design（批准门二） | dev_architecture_design |
| 开发落地 | design → 实现计划 | dev_plan_writing |
| 开发落地 | 已批准实现计划 → TDD 实现 | dev_implementation |
| 测试提质 | 验收各 proposal 的性能与质量要求（Q 条目） | （暂缺） |
