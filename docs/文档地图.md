# 文档地图

| 文档 | 路径 | 简要作用 |
| --- | --- | --- |
| 用户故事 | `docs/product/AXY-<N>-<slug>/story.md`（编号未下发时平铺 `docs/product/<feature>.md`，回填时迁入） | 用户故事 |
| 需求规范 proposal | `docs/product/AXY-<N>-<slug>/proposal.md` | 需求规范（含原型契约） |
| 用户故事总览 | `docs/product/index.md` | 用户故事总览仪表盘 |
| 变更记录 | `docs/product/AXY-<N>-<slug>/change-record.md` | 变更记录（条件性：推翻 / 取代 / 废弃时） |
| 特性开发工件 | `docs/dev/AXY-<N>-<slug>/` | 架构设计（design 主文件 + contracts / testing / adr 拆出）与实现计划（tasks） |
| ADR | `docs/dev/adr/` | 技术决策记录（一决策一文档） |
| 代码目录约定 | `docs/dev/代码目录.md` | 代码目录约定 |
| 基线规范 | `docs/dev/组件划分方法.md`、`docs/dev/编码排版纪律.md` | 组件划分方法与编码排版纪律 |
| 调研报告 | `docs/other/*.md` | 调研存档 |
| 测试文档 | `docs/test/` | 测试文档索引 |
| AI 技能文档 | `.agents/skills/` | 技能清单与技能细则 |
| 常青页 | `docs/intro.md`、`docs/研发流程.md`、本页 | 产品简介、研发流程、文档地图 |
