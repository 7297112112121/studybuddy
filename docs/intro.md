# 产品简介

**学习陪伴伙伴(studybuddy)** 是面向纯软件赛道、有就业 / 深造需求的本科在校大学生的 AI 一体化学业与生涯陪伴平台。产品定位为「**面向 IT 垂直赛道的个性化、有情感的 AI 学习成长伙伴**」,围绕「垂直赛道规划 → 动态任务调度 → 全流程情绪陪伴 → 落地执行采集」形成闭环,解决传统学习规划工具**静态固化、垂直指导缺失、过程陪伴不足**的核心问题。

## 核心能力

产品聚焦三大核心能力:

| 能力 | 说明 |
| --- | --- |
| **AI 学业规划** | 垂直 IT 赛道的生涯路线设计、里程碑规划与动态调整 |
| **情绪陪伴** | 学习过程中的情绪疏导、动力干预与成长激励 |
| **技能实训** | IT 方向课内学习、刷题、项目实战等落地练习场景 |

## 产品价值

1. 落地个性化教育,针对性解决学业规划、学习追踪问题,补齐传统教育工具短板,提升成长实效。
2. 以轻量化架构提供一站式陪伴服务,打破时空限制,促进优质教育资源普惠。
3. 将 RAG、长期记忆、智能体技术融入学习场景,验证智能体在学习陪伴、情感支持场景的落地价值。
4. 不止于知识辅导,兼顾习惯养成、情绪管理、规划能力培养,塑造学生自主成长素养。
5. 重构学习服务模式,助力教育信息化、智慧教育转型,丰富智慧教育产品形态。

## 产品边界

本期产品不拓展以下边界,保障核心能力聚焦:

- 不对接企业 HR 招聘系统
- 不对接本科高校的教务管理系统
- 不提供真人老师一对一辅导服务
