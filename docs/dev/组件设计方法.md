# 组件设计方法

## 适用范围

本文件是组件设计的方法真源:组件草稿技能在方案分析与组件生成时遵循本文;真实 UI 实现可参照。页面级布局结构不在本文范围,见 [布局设计方法](布局设计方法.md)。

## 组件设计原则

- 单一职责与可复用:一个组件只解决一类问题(按钮只触发操作、输入框只录入信息),不承载业务逻辑;不写死业务文案与业务数据,脱离具体业务场景依然成立。
- 一致性:同系列组件共用同一套圆角、阴影、字号、色值、间距;同类型操作的反馈逻辑统一;尺寸、变体、状态的命名规则统一(如 large / medium / small 三档)。
- 状态完整性:基础必选状态为默认、悬浮(Hover)、激活(Active)、禁用(Disabled);按组件类型扩展聚焦、加载、成功、错误、选中、只读、空状态;把组件放进所有业务场景推演,每种用户操作与数据情况都要有对应的视觉呈现。
- 即时反馈:悬浮时样式微变化(颜色/阴影/背景)告知可点击;点击瞬间有按压效果告知已触发;异步操作给加载动画;操作结果给成功/失败提示。
- 边界兼容:文字超长(单行/多行省略、自动换行)、文本为空、超短文本有适配规则;空数据、加载中、超大数据量(滚动/分页)有展示规则;嵌入表格、弹窗、深色模式、不同分辨率下样式不崩坏。
- 可访问性:支持键盘导航(Tab 聚焦、Enter/Space 触发、方向键切换选项);状态区分不只靠颜色,搭配图标、文字、边框变化;HTML 标签与 ARIA 属性语义化。

## 设计工作流(六步)

1. 需求拆解:明确核心用途、使用页面、服务的用户操作;枚举全部变体(风格变体 + 尺寸变体);划定通用能力与业务定制的边界,业务定制不进基础组件。
2. 骨架与信息层级:拆分内部区块(如输入框 = 前缀图标 + 输入区 + 后缀操作 + 底部提示);核心元素占最大视觉权重,辅助元素弱化;相关元素紧邻排布,统一基线对齐。
3. 视觉规格:复用全局色板、字号、圆角、阴影与 8 点栅格间距,不自创数值;尺寸分大(L)中(M)小(S)三档,中号为默认;内边距取 8 的整数倍,同档位规则统一。
4. 全量状态:必选四态全覆盖;业务状态按组件类型补充;状态差异清晰可感知且不突兀,变化幅度见「状态样式公式」。
5. 属性与互斥:定义内容属性(图标/换行/字数上限/可清空)、样式属性(尺寸档位/主题色/实心线框文字)、交互属性(可点击/键盘操作/遮罩关闭);声明互斥规则(加载态禁止点击,禁用态不响应悬浮)。
6. 规范输出:标注全部尺寸、间距、色值、字号数值;写明适用场景、禁忌场景、极端内容处理规则;配套交互说明(触发方式、反馈效果、异常流程、动画时长)。

## 通用尺寸三档

| 档位 | 组件高度 | 适用场景 |
| --- | --- | --- |
| 小型 S | 32px | 表格内操作、紧凑布局、辅助操作 |
| 中型 M | 36px / 40px | 默认尺寸,表单、弹窗、工具栏 |
| 大型 L | 48px | 营销首屏、强引导操作、空状态按钮 |

## 圆角规范

- 小圆角 4px:标签、徽标、小型输入控件。
- 中圆角 8px:默认按钮、输入框、普通卡片。
- 大圆角 12px:大卡片、弹窗、下拉面板。
- 全圆角 50%:图标按钮、头像、徽章。

## 内边距规则

- 横向:小型 12px,中型 16px,大型 24px。
- 纵向:小型 4-8px,中型 8-12px,大型 16px。
- 图标与文字间距固定 8px;内部区块间距 16px(大区块)、8px(小组件)。

## 状态样式公式

- Hover:主色明度降低 8%,或叠加 10% 不透明度的白色遮罩。
- Active:主色明度降低 15%,或叠加 15% 不透明度的黑色遮罩。
- Disabled:整体不透明度 0.4,鼠标样式 `not-allowed`。
- 功能色:错误态 `#F53F3F`,成功态 `#00B42A`,警告态 `#FF7D00`。

## 阴影分层

- 静止态:无阴影或 `0 1px 2px rgba(0,0,0,0.05)`。
- 悬浮/展开态:`0 2px 8px rgba(0,0,0,0.08)`。
- 弹窗/下拉面板:`0 4px 16px rgba(0,0,0,0.12)`。

## 典型组件策略

- 按钮:层级为主按钮(实心填充,一个区域最多 1 个)> 次按钮(线框/浅灰背景)> 文字按钮(无背景)> 危险按钮(红色);点击有微缩放/按压效果;加载态禁止重复点击;纯图标按钮必须配悬浮提示;同一操作区禁止并排多个主按钮,文字长度不一时宽度不忽大忽小。
- 输入框:标签区 + 输入区(前缀/输入内容/后缀操作)+ 底部辅助提示区;聚焦时边框高亮;错误态同时用红色边框、错误文字、警示图标;清空按钮仅悬浮时显示;标签统一顶部对齐或左对齐,不可混用;提示文案固定在输入框下方。
- 卡片:头部(标题 + 右侧操作)+ 内容区 + 底部(操作/补充信息);内部元素左对齐,标题加粗;内边距默认 24px,紧凑小卡片 16px;可点击卡片悬浮时阴影加深并轻微上移,纯展示卡片无悬浮效果。
- 模态弹窗:顶部标题栏(标题 + 关闭按钮)+ 中间内容区 + 底部操作栏(主按钮居右,次按钮居左);宽度小 400px / 中 600px / 大 800px,高度随内容自适应,超出时内部滚动;表单类弹窗点击遮罩不关闭,提示类可关闭;弹出带淡入 + 微缩放动画,背景加半透明遮罩。
- 下拉选择器:触发器(选中内容 + 下拉箭头)+ 下拉面板 + 选项列表;点击展开/收起,选项悬浮高亮,选中项带对勾;支持键盘上下键切换;选项超过 10 条时增加搜索框;面板超出视口时自动翻转方向。

## 组件校验清单

- 必选四态(默认/Hover/Active/Disabled)齐全,业务扩展态按组件类型补齐。
- 尺寸、色值、圆角、间距复用全局规范数值,无自创取值。
- 文字超长、空数据、加载中的处理规则明确。
- 可交互元素均有悬浮与按压反馈。
- 支持键盘聚焦与触发。
- 去掉业务文案后组件仍独立成立。
- 同系列组件视觉风格与交互逻辑一致。
