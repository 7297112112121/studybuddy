# 单元测试纪律

涵盖单元轨用例结构、表驱动、分层 mock 边界、确定性、对齐锁定、单例重置与桩态清理、文件形态、指标合格率——凡编写或修改单元测试的技能在每任务提交前逐条自查的裁判文档。本文件是单元测试规则的真源,规则**包括但不局限于**以下条目,新增单元测试纪律登记于此。

## 用例结构

- 一例一行为:每个用例只验证一个行为,用例名按「前置 + 行为 + 期望」表述;同一行为的多个观察面可在同例多断言,独立行为禁止并例——拆分后各例自带前置,任意单例可独立运行,不依赖前例遗留状态;
- 断言无控制流:断言内禁 if 与分支循环,循环只用于构造与收集,断言收敛为单一布尔或集合比较;
- 竞态与乱序以手工控阀的未决 promise 构造(先暂缓后放行),禁真实时延依赖(setTimeout/sleep)——时序赌注即偶发红。

## 表驱动

- 同构输入逐一断言(正则接受/拒收集、纯函数出入对照)一律 it.each,插值(%s/%i)逐案命名,失败输出直达具体入参;
- 异因用例保持独立用例:各例失败理由不同(空格/长度/@/空)时例名写明理由,不并表——例名即行为文档。

## 分层 mock 边界

- 每层测试只 mock 被测层真实依赖的相邻下一层:组件测试 mock store(useCalendarStore.getState 形状)与 next/navigation,链测试 mock store,store 测试经 vi.stubGlobal 桩 fetch,契约切面测试 mock 会话读取与 logger;
- mock 目标必须是被测物 import 图中的真实模块;重构移动层间依赖时,同任务迁移受影响测试的 mock 目标,禁止保留已解散模块词汇的 mock;
- 组件测试 mock store:仅 getState 消费用 {getState} 形状,兼用选择器订阅时用 Object.assign(vi.fn(sel=>sel(state)),{getState}) 形状,vi.hoisted 供按例改写;
- 负断言(未被调)不作为唯一证据:mock 钉在无人 import 的模块上时负断言恒真,绿测不证明接线正确,依赖 mock 目标存在性门禁兜底——vi.mock 的 "@/…" 目标与含 "/src/" 的相对目标必须在 src/ 下真实存在(裸模块名不校验),校验由 scripts/check-test-mocks.mjs 承担并随 npm run lint 执行。

## 确定性与零桩优先

- 零桩直测为默认形态:纯函数与派生计算一律直接断言,仅被测面真实跨越相邻依赖(如 store 之 fetch、契约切面之会话读取)时引入桩;
- 时间取固定真实日历日字面值(含闰日、跨年、月界/周界),禁相对当前时刻,禁 mock 时钟;
- 期望值用契约锚定的字面值,禁由被测物自身推导;测试两侧同用造数基座构造除外。

## 对齐锁定

- 锁定用例(常量字面值、文案键逐字、wire 形状、路由表)头注声明「改动即有意变更,须同步本测试」;断言强度与头注声明一致——锁字面值声明字面值,锁存在性断言存在性,禁声明存在而断言字面;
- 契约锚存在性断言(如客户端 SDK 方法名)只证接线不证行为,行为语义归接口轨与 E2E 轨;
- 跨轨共享件的生成规则以校验层导出成员为锚做符合性测试(如造号产出断言过 USERNAME_RE),规则漂移时符合性测试先红。

## 模块单例与桩态清理

- 模块单例 store 每例前重置为初始快照(getInitialState()),禁手列字段枚举——增字段漏重置即跨例串态;
- 桩清理逐对象配对:mockReset/mockClear 按需前置,unstubAllGlobals 与 spyOn mockRestore 收尾;跨用例共享的可变桩态经 vi.hoisted 供按例改写。

## 文件形态

- import 全收文件头,禁止中段 import;文件内分节注释横幅可用;
- tests 内引用 src 一律走 @/ 别名(与产品代码同一套解析),禁止相对路径跨入 src,ESLint no-restricted-imports 守增量;vi.mock 目标字符串与 import 寻址同规;
- 文件头注一两行声明被测面与归属(纯函数归属模块、真实链路归哪轨);
- 冒烟用例只证测试基建可用,不承载业务语义。

## 指标合格率

- 分支覆盖率 ≥ 60:开覆盖率跑低于阈值即非零退出;CI PR 阶段分母为变更 src 文件(增量口径),本地 test:report 为全局分母;
- 变异杀死率 ≥ 70:低于 break 即非零退出;CI PR 阶段分母为变更 src 文件,本地 test:mutation 缺省分母 src/services/**;
- 全局口径(合并 master 后的全局监控)本次不建,暂缓。

执行层说明:存量文件不追溯整改,新写/被改到的文件按本约定执行。
