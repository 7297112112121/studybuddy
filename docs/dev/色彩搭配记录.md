# 色彩搭配记录

## 定位与真源声明

- **token 值唯一真源是 `src/app/globals.css`**(`:root` 的 `aurora-*` 组)。本文是配色体系的**语义导读 + 数值快照**,帮助 AI 与新协作者不解码 CSS 就理解主题色;若两者不一致,**以 globals.css 为准**,发现漂移应随当次 PR 修订本文。
- 消费规则(token 类、禁裸色值、组件选型)见 [前端设计规范](./前端设计规范),本文不重复。

## 总体风格

**深色科技风「aurora glass」+ 青→紫渐变品牌色**,匹配产品定位「AI 学业陪伴:理性学习 + 情绪关怀」——青色代表理性、专注、高效;紫色代表创意、情绪、柔和陪伴。

**作用域是关键**:这套暗色视觉只通过 `.aurora-theme` 类挂在 auth 屏根节点上局部生效(globals.css 内重定义语义 token),**不是全局暗色策略**,不改变 ADR-0003 的既有条款。其余页面仍是亮色 shadcn neutral 语义 token(`--background` / `--foreground` 等)。

## 品牌色板(aurora 组,快照)

| token | 快照值 | 名称 | 角色与应用位置 |
| --- | --- | --- | --- |
| `--aurora-ink` | `#0b0f14` | 墨黑蓝 | 暗色底(`.aurora-theme` 的 `--background`)、深色文字反色、暗角遮罩 |
| `--aurora-aqua` | `#2dd4bf` | 薄荷青 | **渐变起点 / 主色**:按钮渐变 from 端、焦点环与输入框描边、勾选图标、任务小圆点、 Aqua/Indigo 光斑 |
| `--aurora-aqua-bright` | `#5eead4` | 亮青 | 渐变中段(via 38%)与标题文字渐变起点,提亮高光 |
| `--aurora-magenta` | `#e879f9` | 香芋紫 | **渐变终点**:按钮渐变 to 端、标题渐变终点、Magenta 光斑、纱幕网格 |
| `--aurora-magenta-deep` | `#a21caf` | 深紫 | 光斑浓墨层,**不进入组件默认态** |
| `--aurora-indigo` | `#6366f1` | 靛蓝 | 中性过渡光斑 |
| `--aurora-indigo-deep` | `#312e81` | 深靛 | 光斑浓墨层,**不进入组件默认态** |

在 `.aurora-theme` 子树内,`--primary` 即 `--aurora-aqua`、`--ring` 同色,因此 shadcn 组件在此作用域内会自然继承品牌色,无需另写色值。

## 渐变定义(快照)

- **主行动按钮**(`SubmitButton`):`bg-linear-[100deg] from-aurora-aqua from-0% via-aurora-aqua-bright via-38% to-aurora-magenta`,外发光 `shadow-aurora-aqua/30`。
- **标题强调文字**(`AuthScreen`):`from-aurora-aqua-bright to-aurora-magenta` 的文字裁切渐变。
- **氛围光斑**(`AuthScreen`):aqua / indigo / magenta 大圆 `blur-3xl` 分层铺底,叠加 `aurora-ink` 暗角与径向衰减;`aurora-veil` 纱幕为 aqua/magenta 双色细网格 + 白色颗粒点阵(见 globals.css `.aurora-theme .aurora-veil`)。

## 语义寓意(供文案与后续页面对齐)

- **青系**(aqua):理性、专注、高效——学习与 AI 的一面;用于可交互、可聚焦、任务与校验成功的元素。
- **紫系**(magenta):创意、情绪、柔和陪伴——情绪关怀的一面;用于氛围、光斑与强调性装饰,不承载语义状态。
- 语义状态色不走品牌色板:错误 `--destructive`、校验汇总 `--warning`(见前端设计规范)。

## 新页面用色指引

- auth 屏之外的新页面:使用标准 shadcn 语义 token,**不得消费 aurora-* 装饰色**;若某页面需要同款暗色视觉,应先走 ADR 流程评估是否把 `.aurora-theme` 泛化为全局主题(ADR-0003 现有条款约束)。
