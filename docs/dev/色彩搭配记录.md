# 色彩搭配记录

## 定位与真源声明

- **token 值唯一真源是 `src/app/globals.css`**(`:root` 的 `aurora-*` 组)。本文是配色体系的**语义导读 + 数值快照**,帮助 AI 与新协作者不解码 CSS 就理解主题色;若两者不一致,**以 globals.css 为准**,发现漂移应随当次 PR 修订本文。
- 消费规则(token 类、禁裸色值、组件选型)见 [前端设计规范](./前端设计规范),本文不重复。

## 总体风格

**深色科技风「深空 + 玻璃」+ 薄荷青品牌色**(ADR-0027,自 calendar 页试验转正):ink 深空底 + 星点视差背景 + 白色半透明玻璃卡面,aqua 薄荷青为主色。匹配产品定位「AI 学业陪伴:理性学习 + 情绪关怀」——青色代表理性、专注、高效;紫系(magenta/indigo)仅用于氛围光斑与装饰,不承载语义。

**全局生效**:`:root` 语义 token 即深空暗色校准值,全站固定暗色、无亮色模式;`--primary` / `--ring` 全局指向 `--aurora-aqua`,shadcn 组件全站自然继承品牌色。不再存在页面级主题作用域(原 `.aurora-theme` / `.calendar-theme` 已随 ADR-0027 移除)。星点背景由根布局挂载的 `StarsBackground`(`src/components/`)统一提供,页面不自带背景层。

## 语义 token 与色板的关系

语义 token(`--background` / `--primary` / `--card` 等,真源 globals.css `:root`)是组件消费的**唯一通道**:卡面/悬浮层为白色半透明(`--card` 白 8%、`--border` 白 12%),底色透星点;`--accent` 为 aqua 15% 薄荷洗色(hover/选中)。组件**默认态一律走语义 token,禁直书 aurora-\***;aurora 组仅限装饰元素(光斑、纱幕、星层)与 token 派生定义。

## 渐变定义(快照)

- **auth 签名提交按钮**(`SubmitButton`,存量视觉):`bg-linear-[100deg] from-aurora-aqua from-0% via-aurora-aqua-bright via-38% to-aurora-magenta`,外发光 `shadow-aurora-aqua/30`。**新按钮一律纯色**(设计裁决:渐变不作按钮控件面)。
- **标题强调文字**(`AuthScreen`):`from-aurora-aqua-bright to-aurora-magenta` 的文字裁切渐变。
- **氛围装饰**(`AuthScreen`):aqua / indigo / magenta 大圆 `blur-3xl` 分层铺底,叠加 `aurora-ink` 暗角与径向衰减;`aurora-veil` 纱幕为 aqua/magenta 双色细网格 + 白色颗粒点阵(见 globals.css `.aurora-veil`)。

## 语义寓意(供文案与后续页面对齐)

- **青系**(aqua):理性、专注、高效——学习与 AI 的一面;用于可交互、可聚焦、任务与校验成功的元素。
- **紫系**(magenta/indigo):创意、情绪、柔和陪伴——情绪关怀的一面;仅用于氛围、光斑与强调性装饰,不承载语义状态。
- 语义状态色不走品牌色板:错误 `--destructive`、校验汇总 `--warning`(见前端设计规范)。

## 新页面用色指引

- 一律使用标准 shadcn 语义 token(现已为深空暗色校准),**禁裸色值与浅色假设**(全站固定暗色,ADR-0027);
- 星点背景无需页面自挂——根布局 `StarsBackground` 已覆盖,页面直接透出即可;
- 需要新的装饰手法或色板扩充时,先在 `globals.css` `@theme` 增 token(ADR-0003),涉及主题策略变更(亮色模式、手动切换)须另立 ADR。
