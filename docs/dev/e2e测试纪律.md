# e2e 测试纪律

涵盖端到端测试真依赖与门控边界、造号与并行隔离、web-first 断言与负空间直证、定位器契约、URL 周锚与时间两类、进入路径、契约对齐与共享基座、用例形态——凡编写或修改端到端测试(e2e/)的技能在每任务提交前逐条自查的裁判文档。本文件是端到端测试规则的真源,规则**包括但不局限于**以下条目,新增端到端测试纪律登记于此。

## 真依赖与门控边界

- 断言目标恒为「真实浏览器中的生产构建产物」:webServer 先 build 再 start,对 url 探活后执行;基础设施(PG/Redis)与登录链路永不桩接——真依赖直连是本轨存在意义;
- 防护语义(限流等)不归本轨承载:归接口测试环境与生产运行时;e2e 需关断时经环境变量显式门控且仅 webServer 进程注入,门控语义在产品配置侧以注释留痕,禁在产品代码写死测试分支;
- 拟真度取舍(浏览器矩阵、失败重试、trace 时机、并行度)在 config 注释留痕;CI 复用已有服务一律关闭,防误连陈旧产物假绿;端口覆盖时受端口影响的服务端配置(如 trustedOrigins)随端口对齐。

## 造号与并行

- 隔离靠唯一造号替代 teardown:每例独立账户,任意单例可独立运行,不依赖前例遗留数据;并行 worker 安全由造号唯一性承担,禁以串行节流或 sleep 替代根因修复;
- 测试内禁建重试循环:偶发失败归 CI retries 与节奏根因,测试内吞错换号重试即遮蔽不稳定并制造双份数据。

## 断言与负空间

- 全部等待走 web-first 断言(expect 自动重试),禁 waitForTimeout 与裸 waitFor;人为延迟只放 route 拦截的服务端侧(模拟慢响应窗口),不污染客户端时序;
- 负空间直证在 UI 层保留:未登录响应原文不含受保护内容(逐字面负断言)、删除确认层无输入控件、秒位泄漏、差异字样、冲突提示缺位;
- 错误态断言锚 ARIA 契约(aria-invalid、role=alert、role=status),禁锚 CSS 类与实现类名。

## 定位器契约

- 语义定位器优先(getByRole/getByTestId/getByText 与产品 data-testid);降级用 #id 或 CSS 时必须留根因注释(如导航离开的页树隐藏保留在 DOM 致 label 双匹配);
- 断言锚须独占于被测行为:换视图仍满足的文案(如任何视图都常驻的侧栏月标)只证在场不证视图,须收窄到行为独有锚(testid、属性、独占文案);
- 不确定产品契约时先读组件源码取锚(testid、aria-label、i18n 文案),禁凭用例旧文猜锚。

## URL 周锚与时间两类

- 周一锚深链(?week=)是日历定位唯一参数;业务区间用例取固定周一字面深链,禁相对当前时刻算术——跨周/跨月分支每次运行确定性执行;非法与缺省的回退语义以负例用例钉住(含非周一的合法日期);
- 今日锚语义(实时线、今日高亮、今日读域)保留真实时钟——业务固定锚与时效核验两类不混;
- 未登录直访的守卫语义含响应原文级断言(postponed shell 不携带受保护内容,重定向由客户端完成的形态如实断言)。

## 进入路径与契约对齐

- auth 流程用例(注册、登录、退出、会话守卫、校验链)走 UI 全真;非 auth 目标用例的进入路径取最短直达深链,禁为到达而重复走过被测流程之外的交互(死路径中间导航);
- 会话多形态借同 context 新页与新 context 表达(有历史/无历史),不重复登录;
- 重构移除或变更 UI 交互时,受影响 e2e 用例同任务改写或删除——被测交互已不存在的用例即假覆盖,留死例比缺例更具误导;深链参数受支持性以路由解析真源为准,不以旧用例在场为凭。

## 共享基座与用例形态

- 多消费者交互基座(auth 注册/登录/退出、点击槽建条、新建建条、色块定位、字面日期)唯一实现落 e2e/helpers,禁文件内私有复制;单消费者定位器留各 spec 文件内;造号唯一实现跨轨归 tests/support;
- 独立行为拆例,同链路纯复制例不立——同输入证不出「行为一致」;
- 例名行为化(前置+行为+期望),禁位置序号前缀,需求溯源码除外;
- 各 spec 文件关注单一视图域,产品视图域合并时用例家族随之迁移归并。
