# 代码目录

本文用图呈现 `src/` 的目录树、路由、业务模块与数据流向。

## 目录树

```
studybuddy/
├─ src/
│  ├─ app/                      # 路由层：薄壳（鉴权/组装/返回）
│  │  ├─ (auth)/                # 登录/注册布局组（不影响 URL）
│  │  ├─ (app)/                 # 主应用布局组（服务端会话守卫）
│  │  └─ api/auth/[...all]/     # Better Auth 托管端点
│  ├─ modules/                  # 业务域，垂直切片（内部结构见「业务模块」）
│  │  └─ <m>/
│  ├─ agent/                    # AI 能力子系统
│  ├─ db/                       # client 单例 + schema barrel + migrations/
│  ├─ lib/                      # better-auth、redis、routes、date、action
│  ├─ components/               # 跨模块共享组件
│  │  ├─ ui/                    # shadcn/ui 基础组件
│  │  └─ <共享组件>.tsx          # 跨模块展示组件
│  ├─ stores/                   # zustand（仅纯 UI 状态）
│  ├─ i18n/                     # next-intl 请求配置
│  └─ locales/                  # i18n 文案（zh-CN）
├─ tests/                       # 单元测试，按域分目录
├─ e2e/                         # Playwright 用例
├─ docs/  website/              # 文档与文档站
└─ Dockerfile  compose.yaml  Caddyfile    # 部署单元
```

## 路由

```
URL 空间

/ ──按登录态分流──▶ 已登录 → (app) 布局组
│                  未登录 → (auth) 布局组
│
├─ (auth) 布局组
│   └─ <page>/      认证页 ──已登录访问──▶ 重定向回 (app)
│
└─ (app) 布局组
    └─ layout.tsx 服务端守卫：未登录 ──▶ redirect 到 (auth)
        └─ <page>/   业务页

API 端点
/api/<handler>   Better Auth 全部 HTTP 端点（注册/登录/登出/会话）
```

## 业务模块

模块内部统一形状，文件即分层：

```
src/modules/<m>/
┌─ 展示层 ─────────────────────────────────────────┐
│ components/        模块私有 UI                    │
│ useClientScreen.ts 客户端逻辑代码                  │
├─ 编排层 ─────────────────────────────────────────┤
│ actions.ts       服务端增删改唯一入口（'use server'）│
│ index.ts         模块对外导出                    │
├─ 逻辑层 ─────────────────────────────────────────┤
│ service.ts       增删改逻辑                    │
│ queries.ts       服务端查询唯一调用入口与查询逻辑（RSC page 直接调用）│
│ validators.ts     校验规则（zod）                 │
├─ 数据层 ─────────────────────────────────────────┤
│ schema.ts          drizzle 表属主                  │
└──────────────────────────────────────────────────┘
```

## 数据流向

```
读（RSC）
  page.tsx ──▶ modules/<m>/queries ──▶ db/client ──▶ PostgreSQL
     └─ props 下行 ──▶ 模块 components

写（Server Action）
  模块 components ──▶ modules/<m>/actions ──▶ service ──▶ db/client ──▶ PostgreSQL
       ▲                └─ revalidatePath ──▶ RSC 重取对账

会话
  better-auth.client ──▶ /api/auth/[...all] ──▶ better-auth.server ──▶ PostgreSQL
  服务端读会话：page / layout ──▶ modules/auth getCurrentSession ──▶ auth.api.getSession
```
