# Proposal: AXY-23 日程周视图

## 1. 摘要与状态

## 2. 目标与背景

有日程计划的本科学生已能经 AXY-22 逐日记录日程,但月视图 + 当日详情的形态看不出「一周的节奏」——哪几天空、哪几天满、一天里时间段怎么咬合。本特性在 AXY-22 条目数据之上新增周视图:一周 7 天 × 24 小时摊开成时间网格,条目按时段落位,辅以实时线标示「现在」,并支持在网格上直接创建与编辑([故事陈述](./story))。条目数据模型零改动(见 11.2 领域模型),全部增量在呈现与交互层。

## 3. 范围与非目标

### 3.1 范围(做什么)

- `/calendar` 新增周视图:7 列(周一为首,D-07)× 24 小时时间网格,槽粒度 30 分钟(F-05);条目按所属日期与时间段渲染为色块;不带时间条目展示于全天区(D-06)。
- 实时线:视图含今天时显示于当前钟点并自动更新(D-05)。
- 网格直接操作:点击空白槽创建(时间按槽预填,F-05)、点击色块打开编辑卡编辑/删除(D-04)。
- `/calendar` 默认视图由月视图改为周视图(D-02,C-02);周/月视图自由切换,数据一致。
- 窄屏降级:7 列压缩至最小列宽、必要时横向滚动(D-09)。

### 3.2 非目标(不做什么)

| # | 不做 | 理由 |
| - | ---- | ---- |
| 1 | 拖拽移动色块、拖边调整时长 | 点选式编辑(点槽创建/点块编辑)已满足故事诉求(D-04);拖拽属重交互,需要时另立故事 |
| 2 | 地点、标签 / 分类、每条目独立颜色 | 编辑卡仅文字+时间两字段(D-03);分类/标签/颜色体系承 AXY-22 C-01 裁定本期不做,采纳时另立故事 |
| 3 | 修改 AXY-22 条目数据模型(新属性 / 新状态 / 新接口) | 周视图是呈现与交互层增量,读写完全复用 AXY-22 既有接口(R7) |
| 4 | 跨午夜时间段 | 继承 AXY-22 F-03:结束与开始同属所选日期,不跨午夜 |
| 5 | 移动端专属周视图形态(如单日纵列降级) | 窄屏按横向滚动处理(D-09),不另做移动端布局 |

## 5. 术语与路由

| 术语 | 含义 |
| ---- | ---- |
| 日程日历页 | 受保护路由页 `/calendar`(AXY-22 已实现):本期默认周视图(D-02),可切月视图 |

| 编辑卡 | 点色块/全天区条目弹出的对话框:文字+时间两字段(D-03),复用 AXY-22 F-01—F-03 |

### 11.2 领域模型(四问与双向核对)

四问各成一表,正文引用实体、状态、事件时与本章口径一致。**本特性零模型增量**——下表为沿承性登记,证明「不做什么」在模型层成立。

**概念与状态**

| 实体 | 属性 | 状态 | 状态流转 |
| ---- | ---- | ---- | ---- |
| 条目 | 归属账号、所属日期、事项文本、开始时间(可选)、结束时间(可选)——全部沿用 AXY-22 口径,本特性零增改 | 已记录(唯一状态,沿承) | 无(沿承 AXY-22:创建即存在,删除即消失) |
| 周视图 | 不设为实体:仅呈现态(所在周、视图切换态为 UI 状态,不入模型) | — | — |

**状态义务**(没人须行动的状态不是队列)

| 状态 | 谁须行动 | 义务 | 关联 |
| ---- | ---- | ---- | ---- |
| 条目·已记录 | 无人 | 沿承 AXY-22:纯记录,不构成须行动队列(实时线只是「现在」的标示,不是催办) | AXY-22 非目标 #2 |

### 14.2 各演示态契约(可构建级)

**演示态 1 · 周视图总览**
- 入口:登录后进入 `/calendar` 即本态(路由行为 #2,R1);未登录直达按路由行为 #1 挡回;
- 布局块:页头(标题「日程日历」+ 周/月切换控件 + 周导航「上一周 / 今天 / 下一周」)→ 星期表头(周一为首 7 列,今天列高亮,D-07)→ 全天区横栏(每列该日不带时间条目,D-06)→ 时间网格(00:00–24:00 纵轴,30 分钟一槽 F-05;带时间条目按所属列与时段渲染为色块,时间点条目为 30 分钟高短色块 D-12;色块单一品牌色 D-11)→ 实时线(当前钟点,含今天时显示 D-05);
- 视觉 / 交互状态:打开即滚动锚定当前时段(D-10);实时线每分钟更新(F-06);重叠色块同列横向并列均分列宽(边界 #2);窄屏 7 列最小列宽、横向滚动,全天区与表头保持可见(D-09 / R8);
- 空态 / 边界:加载中加载态;失败呈 E-05 可重试(R9);
- 关联 R:R1、R2、R8、R9、R11。

**演示态 2 · 网格点击创建**
- 入口:演示态 1 网格中点击任一空白时间槽;
- 布局块:创建卡(对话框,居中):事项文本(AXY-22 F-01)→ 开始时间(预填所点槽起点 F-05,可精调至分钟)→ 结束时间(留空,可填;控件规则同 AXY-22 F-03)→「保存」/「取消」;
- 视觉 / 交互状态:提交中「保存」置灰不可重复提交;校验失败逐字呈现 AXY-22 E-01 / E-03,修正后即时消除;保存失败呈 AXY-22 E-02 且网格不变;
- 空态 / 边界:仅填文本保存 → 创建时间点条目,以短色块呈现(D-12);
- 关联 R:R4、R3(校验同款)。

**演示态 3 · 点色块编辑与删除**
- 入口:演示态 1 网格中点击任一色块;
- 布局块:编辑卡(同演示态 2 布局,预填原值)→「保存」/「删除」/「取消」;删除 → 二次确认层(确认/取消,无额外输入);
- 视觉 / 交互状态:保存后色块即时更新(R3);删除确认后色块消失,取消则保留;提交中置灰(AXY-22 R12 同款行为);
- 空态 / 边界:删除该周最后一条带时间条目后,若整周无条目 → 进入演示态 5 空态;
- 关联 R:R3。

**演示态 4 · 全天区**
- 入口:演示态 1 中某列全天区已有条目(如周一「交英语作业」);
- 布局块:全天区横栏内该列的文字条目(无时间标注);时间网格该列无对应色块(D-06);
- 视觉 / 交互状态:点击全天区条目 → 编辑卡(同演示态 3,时间字段为空可补填);
- 空态 / 边界:全天区条目过多时横栏内纵向堆叠,不侵占时间网格;
- 关联 R:R5、R3。

**演示态 5 · 空周与视图切换一致**
- 入口:周导航翻至无任何条目的一周;或周/月切换控件往返;
- 布局块:空周 → 网格区域内空态文案 E-04;切「月」→ AXY-22 月视图(默认当前月,路由行为 #3);切回「周」→ 保持所在周;
- 视觉 / 交互状态:全程 URL 为 `/calendar`(R10);月视图创建的条目切回周视图可见(R6);
- 空态 / 边界:不含今天的周实时线隐藏(D-05 / R2);
- 关联 R:R6、R10、R11。
