# 用户故事

| 编号 | AXY-19 | 优先级 | P1 | 故事点 | 3 |
| ---- | ---- | ------ | ---- | ------ | ---- |

**状态**：已批准（2026-11-15 自 AXY-13 拆分设立，继承原批准范围；编号 AXY-19 由项目管理平台下发）

## 故事主干

**作为** 已完成统一分配、但总有几天撞车的本科学生，**我想要** 进入日视图把冲突的日子逐个调开并最终生成完整计划，**以便** 特殊日子也能单独安排，计划以零冲突收尾。

## 目标 / 非目标 / 反目标

- **目标**：冲突逐日消解到零后完成规划，统一层参数在微调阶段保持稳定。
- **非目标**：修改统一层参数（日期区间 / 默认时间范围 / 一键错开——微调阶段锁定，见 AC-2 / AC-3）；任务呈现（归 AXY-10）。
- **反目标**：微调阶段改统一层参数后逐日微调静默失效——阶段锁定的意义被破坏即失败。

## 验收标准（AC）

> 本故事 AC 承接 AXY-13 拆分出的原 AC-8–AC-14（原文不变，编号按本故事重排）。

1. **给定** 统一分配页仍有 4 天时间重叠；**当** 点「完成分配，进入微调」；**则** 允许进入；页面切到日视图并停在第一个冲突日 11/05，顶部进度条显示「还有 4 天时间重叠」，底部主按钮不可用且写「完成课程规划（还有 4 天重叠）」 〔走查：演示态 1〕
2. **给定** 已进入时间微调阶段；**当** 查看左栏卡片与底部操作条；**则** 卡片只有「统一分配 · 已锁定 / 不可再改」+ 日期与每日时间两行只读信息，无任何日期或时间输入；「上一步」「一键错开」「恢复默认」均不出现 〔走查：演示态 2〕
3. **给定** 已进入时间微调阶段，某课日期区间为 11/05–11/14；**当** 在月历上按住 11/20 拖向 11/24；**则** 日期区间仍为 11/05–11/14，不出现拖选高亮，只切到按住那天（11/20）的日视图 〔走查：演示态 2〕
4. **给定** 某课默认 19:00–19:45，11/11 当天也为此范围；**当** 在日视图把 11/11 拖成 18:00–20:00；**则** 只有 11/11 变为 18:00–20:00，其余日子仍是 19:00–19:45；月格 11/11 的任务条带左侧竖线并显示 18:00–20:00，日视图块带「单日」标签，卡片出现「1 天单独微调」与可恢复的明细行 〔走查：演示态 3〕
5. **给定** 某课已有 1 天单独微调；**当** 把该天改回 19:00–19:45；**则** 该条例外自动消失，卡片「N 天单独微调」计数归零，月格竖线与日视图「单日」标签一并消失 〔走查：演示态 3〕
6. **给定** 时间微调阶段有 11/05、11/06、11/07、11/08 共 4 天冲突；**当** 连续点「跳到下一处」；**则** 依次定位到 11/05、11/06、11/07、11/08 的日视图，到最后一处后回到第一个；每次跳转不改动任何时间范围 〔走查：演示态 4〕
7. **给定** 逐日把冲突消解到 0 天；**当** 点「完成课程规划」；**则** 按钮恢复可用并进入完成页，展示课程数、每日总用时、覆盖天数、单独微调天数与逐门明细；出口为「查看日历本」与「重新规划」，后者清空已选课程回到选课页 〔走查：演示态 5〕

### 各演示态契约

**演示态 1 · 带冲突进入微调**
- 入口：统一分配页（AXY-13 演示态 2）存在时间重叠时点「完成分配，进入微调」；
- 布局块：顶部进度条（「还有 N 天时间重叠」）→ 日视图（停第一个冲突日）→ 底部主按钮（不可用，文案「完成课程规划（还有 N 天重叠）」）；
- 交互：当用户在统一分配页仍有时间重叠时点「完成分配，进入微调」（主按钮）时，系统允许带冲突进入并停在第一个冲突日的日视图，以实现冲突逐日消解的工作流（AC-1）；当用户查看进度条、按钮文案与月格角标时，系统呈现同一份冲突天数，以实现三处数字同源一致（见 DoD）；
- 空态 / 边界：无冲突进入时主按钮直接可用。

**演示态 2 · 统一层锁定**
- 入口：进入微调阶段后的任意时刻查看左栏卡片与操作条；
- 布局块：左栏卡片仅「统一分配 · 已锁定 / 不可再改」+ 日期与每日时间两行只读信息；底部无「上一步」「一键错开」「恢复默认」；
- 交互：当用户在月历按住拖选（月历网格）时，系统不出现拖选高亮、只切换到按住那天的日视图，以实现微调阶段统一层锁定（AC-3）；当用户查看左栏卡片与底部操作条时，系统不提供任何日期或时间输入、「上一步」「一键错开」「恢复默认」均不存在，以实现统一层参数微调期不可改（AC-2）；
- 空态 / 边界：服务端同样拒绝统一层改动（见 DoD）。

**演示态 3 · 单日微调**
- 入口：日视图选中某天，拖动其时间块；
- 布局块：日视图时刻轴（AXY-10 载体）+ 月历（同步竖线标记）+ 卡片「N 天单独微调」计数与明细行；
- 交互：当用户在日视图把 11/11 的时间块（时刻轴拖拽）拖成 18:00–20:00 时，系统仅写入该天的单日例外（其余日子保持默认 19:00–19:45），月格 11/11 任务条带左侧竖线并显示 18:00–20:00、日视图块带「单日」标签、卡片出现「1 天单独微调」与可恢复明细行，以实现特殊日子单独安排（AC-4）；当用户把该天时间块（时刻轴拖拽）改回默认 19:00–19:45 时，系统删除该条例外并把计数归零、竖线与标签一并消失，以实现例外可完全撤销（AC-5）；
- 空态 / 边界：单日例外不改变其余日期的默认范围。

**演示态 4 · 跳到下一处**
- 入口：微调阶段点「跳到下一处」；
- 交互：当用户连续点「跳到下一处」（冲突导航按钮）时，系统依次定位 11/05、11/06、11/07、11/08 的日视图并在末尾回绕到第一个、跳转不改动任何时间范围，以实现冲突逐日巡检（AC-6）；
- 空态 / 边界：无冲突时按钮隐藏。

**演示态 5 · 完成课程规划**
- 入口：冲突消解到 0 天后点「完成课程规划」；
- 布局块：完成页（课程数、每日总用时、覆盖天数、单独微调天数、逐门明细）+ 出口「查看日历本」「重新规划」；
- 交互：当用户把冲突消解到 0 天后查看底部主按钮时，系统恢复「完成课程规划」可用，以实现零冲突完成门槛（AC-7 前置）；当用户点「查看日历本」（出口按钮）时，系统状态转移至日历本（AXY-10），以实现规划结果查看；当用户点「重新规划」（出口按钮）时，系统清空已选课程并回选课页，以实现整份计划推倒重来（AC-7）；
- 空态 / 边界：单独微调天数为 0 时该统计行显示 0。
