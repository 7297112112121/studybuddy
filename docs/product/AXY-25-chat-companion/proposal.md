| 项 | 值 |

## 2. 目标与背景

学习间隙想松口气的时候，用户打开应用就有一个记得自己生活细节的伙伴陪TA自由闲聊吐槽，压力被接住、重新有劲回到学习（故事陈述）。这是产品简介「RAG、长期记忆、智能体融入学习场景」承诺的第一个落地特性，补上三大核心能力中「情绪陪伴」的空白；已实现的登录（AXY-8）与日程（AXY-22/23）均未涉及 AI，本特性是首个智能体故事。

## 3. 范围与非目标

### 3.1 范围（做什么）

已登录用户在工作台内嵌的伙伴面板中与伙伴单线持续对话：回复流式逐字呈现、短口语化；伙伴先接住情绪再鼓励；隔天以上回访时主动引用聊过的生活细节续接话题；聊天记录与记忆跟账号走；新用户正常迎接；回复失败可重试。Agent 框架（AgentScope）与流式输出（AI SDK）属实现层约束，不在本规范展开（见开放问题 1）。

### 3.2 非目标（不做什么）

| # | 不做 | 理由 |
| - | ---- | ---- |
| 1 | 记忆管理界面（查看 / 编辑 / 删除记忆） | 第一版聚焦「聊得上、记得住、接得住」；管理界面信息敏感，值得另立故事（D-06） |
| 2 | 伙伴主动发起对话（晚间问候等推送） | 跨出「用户打开才聊」的边界，涉及通知通道，另立故事（D-06） |
| 3 | 语音与图片消息 | 文字已覆盖闲聊主链路（D-06） |
| 4 | 人设与称呼自定义 | 人设是产品统一资产，不是用户设置项（D-06） |
| 5 | 多会话与「开启新对话」 | 陪伴关系是「一个持续的它」，分对话管理是效率工具心智（D-05） |
| 6 | 记忆重置 / 「重新认识我」 | 随记忆管理界面一并排除（非目标 1） |

## 5. 术语与路由

| 术语 | 含义 |
| ---- | ---- |
| 工作台 | 登录后的主界面（AXY-8 守卫承接），本特性在其中新增伙伴面板 |
| 伙伴 | 本特性的对话角色，有固定称呼与人设（文案 design 阶段定稿） |
| 伙伴面板 | 工作台内嵌的单线对话区域，本特性的唯一界面 |
| 记忆 | 伙伴对用户生活细节的长期印象，跟账号走，用户不可见其形态 |
| 单线对话 | 每用户恒一条对话线，接着上次聊，无「新对话」概念 |

### 路由行为表（守卫与跳转的单一事实源）

无新增路由行为。伙伴面板随工作台呈现，未登录守卫沿用 AXY-8（其 AC-7：直接访问被挡回登录页），本特性不新增任何页面级跳转。

## 10. 边界与约束

| # | 边界 | 处理 |
| - | ---- | ---- |
| 1 | 输入长度：1–2000 字，空内容不可发送（规则见 F-01） | 超限呈现 E-01，不发送 |
| 2 | 回复生成中用户继续操作：输入框可继续打字，发送钮置灰至当前回复完成或失败（D-09） | 不出现交错回复 |
| 3 | 会话过期（登录态失效）时发送消息 | 沿用 AXY-8 守卫，被挡回登录页，重新登录后回到工作台 |
| 4 | 与既有特性交互：伙伴面板嵌入工作台，不得改变工作台既有功能（日程等）的布局与行为 | 面板为新增区域，既有功能不动 |

### 11.2 领域模型（四问与双向核对）

**概念与状态**

| 实体 | 属性 | 状态 | 状态流转 |
| ---- | ---- | ---- | -------- |
| 伙伴 | 称呼（产品统一，固定） | 无（恒在角色，非数据实体） | 无 |
| 对话 | 消息序列；每用户恒一条（D-05） | 无 | 无 |
| 消息 | 角色（用户 / 伙伴）、内容、发生时间 | 用户消息：已发送；伙伴消息：生成中 / 已完成 / 失败 | 发送 → 生成中；流式完成 → 已完成；异常 → 失败 →（重试）→ 生成中 |
| 记忆 | 内容（生活细节摘要）、归属账号 | 无（系统自动沉淀，用户不可见形态） | 无 |

**状态义务**（没人须行动的状态不是队列）

| 状态 | 谁须行动 | 义务 | 关联 |
| ---- | -------- | ---- | ---- |
| 伙伴消息 · 生成中 | 系统 | 流式产出回复直至完成或失败 | R1 |
| 伙伴消息 · 失败 | 用户 | 点重试重新生成 | R6（E-02） |
| 用户消息 · 已发送 | 系统 | 落库并触发伙伴生成 | R1 |

**领域事件**

| 事件（领域语言） | 触发 | 结果 | 关联 |
| ---------------- | ---- | ---- | ---- |
| 消息已发送 | 用户点发送（F-01 校验通过） | 用户消息落库；伙伴开始生成回复 | R1 |
| 回复已完成 | 流式输出结束 | 伙伴消息落库为已完成；触发记忆沉淀判定 | R1 / R2 |
| 记忆已沉淀 | 系统判定对话中出现值得长期保留的生活细节 | 记忆归属当前账号，供后续会话检索 | R2 / R3 |

**负空间**（业务刻意不设的概念）

| 刻意不设 | 理由 | 依据 |
| -------- | ---- | ---- |
| 多会话 / 会话列表 | 单线陪伴心智；分对话是效率工具概念 | D-05 / 非目标 5 |
| 记忆管理界面 | 第一版聚焦主线；管理属敏感操作另立故事 | D-06 / 非目标 1 |
| 伙伴主动发起对话 | 跨出「用户打开才聊」边界，涉及通知通道 | D-06 / 非目标 2 |
| 语音 / 图片消息 | 文字覆盖主链路 | D-06 / 非目标 3 |
| 人设自定义 | 人设是产品统一资产 | D-06 / 非目标 4 |
| 记忆重置 | 随记忆管理界面一并排除 | 非目标 1 / 非目标 6 |

**界面字段 ↔ 模型属性核对**

| 字段 | F 编号 | 模型属性 | 核对结果 |
| ---- | ------ | -------- | -------- |
| 消息输入框 | F-01 | 消息 · 内容 | 落模 |
| 消息气泡 | — | 消息 · 内容 + 角色 | 落模 |
| 失败提示与重试按钮 | — | 消息 · 失败状态 | 落模（E-02 承载文案） |
| 发送按钮 | — | 动作（非字段） | 不落模（触发「消息已发送」事件） |

### 14.2 各演示态契约（可构建级）

**演示态 1 · 工作台伙伴面板 · 对话进行中**

- 入口：登录后打开应用进入工作台（守卫沿用 AXY-8，无新增路由行为），伙伴面板为工作台内嵌区域，打开即见；
- 布局条目：`studybuddyui/layouts/workbench-layout`（视觉真源，含块级布局；无动效规格——开发者确认本布局不做动画）；
- 布局块：面板标题行（伙伴称呼，design 定稿）；对话消息区（用户与伙伴消息气泡按时间排列，回复逐字流式渲染，R1）；输入区（消息输入框 F-01 + 发送按钮）；
- 视觉 / 交互状态：回复生成中发送钮置灰、输入框可继续打字（D-09 / 边界 2）；流式期间该条气泡逐字增长；超限发送时 E-01 呈现于输入框下方，文案消除时机：修改输入内容后即消；
- 空态 / 边界：本态要求已有若干轮对话；空态见演示态 3，失败见演示态 4；
- 关联 R：R1、R4、R7。

**演示态 2 · 隔天回访 · 主动续上**

- 入口：距上次对话间隔一天以上，登录（任意设备）打开工作台即入本态；
- 布局条目：同演示态 1（同一面板条目）；
- 布局块：与演示态 1 相同三块；历史消息完整呈现（R3），最新一条伙伴回复主动引用旧事（R2）；
- 视觉 / 交互状态：无本态特有交互，沿用演示态 1 全部状态；
- 空态 / 边界：历史加载期间消息区呈现加载态；跨设备仅影响数据来源（R3），界面表现一致；
- 关联 R：R2、R3。

**演示态 3 · 新用户首聊空态**

- 入口：新注册用户首次打开工作台；
- 布局条目：同演示态 1；
- 布局块：对话消息区无历史消息，呈现伙伴迎接语（正常迎接并开始认识用户，R5）；输入区同演示态 1；
- 视觉 / 交互状态：迎接语为伙伴第一条消息（角色为伙伴），发送首条消息后面板转入演示态 1 的常规流转；
- 空态 / 边界：空态本身即本态；不出现报错或无响应（R5）；
- 关联 R：R5。

**演示态 4 · 回复失败 · 重试**

- 入口：演示态 1 对话中，回复未正常返回（如网络中断）；
- 布局条目：同演示态 1；
- 布局块：与演示态 1 相同三块；失败呈现在对应消息气泡位置（E-02 文案 + 重试按钮）；
- 视觉 / 交互状态：失败时已发送消息保留不消失（R6）；点重试后该条转为生成中（流式渲染恢复）；发送钮状态同边界 2；
- 空态 / 边界：重试再次失败则停留本态，可继续重试；
- 关联 R：R6。
