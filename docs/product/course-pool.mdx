## 故事主干

**作为** 想补技能却不知道从哪门学起的本科学生，**我想要** 在课程池里按方向筛出这条赛道上的课程并看清每门的难度与预计时长，**以便** 判断这门课我能不能学、值不值得排进计划。

## 目标 / 非目标 / 反目标

- **目标**：打开课程池即见全量分组列表，三次操作内筛出目标课程集合。
- **非目标**：先修拦截与状态改后重算（已拆出）；导入的运营界面形式（由实现定稿）；课程学习内容本身（负空间）；全局搜索与个性化推荐（负空间）。
- **反目标**：用「全部平铺不分组的无限滚动列表」替代分组结构——筛选效率即使不降低，可扫读性也属失败。

## 验收标准（AC）

1. **给定** 课程池已导入 16 门课程；**当** 打开课程池；**则** 按 5 个方向分组全量列出，每组首行为组头「方向 · N 门 · 可选 M 门」；每行展示名称、方向、难度、预计时长、章节数、先修数、学习状态；首屏 ≤ 2 秒 〔走查：演示态 1〕
2. **给定** 课程池 16 门，方向与难度均为「全部」；**当** 方向选「后端」、难度选「进阶」；**则** 结果 3 门（数据结构与算法基础、计算机网络、数据库原理与 SQL），结果条写「共 3 门 · 后端 · 进阶」，仅保留后端一个分组 〔走查：演示态 1〕
3. **给定** 课程池 16 门，方向与难度均为「全部」；**当** 打开「仅看未修习」；**则** 结果 11 门且全部为未开始状态；已完成的 2 门、学习中的 2 门、待复习的 1 门均不出现 〔走查：演示态 1〕
4. **给定** 课程池 16 门，方向与难度均为「全部」、开关关闭；**当** 方向选「数据」、难度选「高阶」；**则** 结果 0 门，展示空态「没有符合条件的课程」；点「清空筛选」后恢复 16 门且开关回到关闭 〔走查：演示态 2〕
9. **给定** 导入批次中有一条课程方向、难度、先修、章节齐全但缺预计时长；**当** 执行导入；**则** 该条被拒并提示缺失字段，池内不出现该课程，课程总数不变 〔走查：行为说明 1〕

### 各演示态契约

**演示态 1 · 课程池列表（含筛选）**
- 入口：侧栏「课程池」导航；
- 布局块：筛选栏（方向下拉「全部 + 5 方向」、难度下拉「全部 + 档位」、「仅看未修习」开关、「清空筛选」按钮、结果条「共 N 门 · 〈方向〉 · 〈难度〉」）→ 按方向分组的列表（每组组头「方向 · N 门 · 可选 M 门」+ 课程行）；
- 内容与数据形状：每行展示名称、方向、难度、预计时长、章节数、先修数、学习状态四值；方向五值 = 后端 / 前端 / 算法 / 数据 / 测试，难度三档 = 入门 / 进阶 / 高阶（组内排序按入门 → 进阶 → 高阶，再按时长升序）；种子数据集 16 门沿用已批准的原线框数据（git 历史 `Us04CoursePoolWireframe` 可考，含七项字段与四值状态）；
- 交互：当用户在方向下拉选「后端」、难度下拉选「进阶」（下拉选择器）时，系统仅保留后端分组并在结果条显示「共 3 门 · 后端 · 进阶」，以实现按方向与难度过滤（AC-2）；当用户打开「仅看未修习」（开关）时，系统只保留学习状态为未开始的 11 门，以实现未修习过滤（AC-3）；组头「可选 M 门」= 组内未被先修拦截的课数（口径与改后重算见 AXY-17）；当用户点击课程行（列表行）时，系统状态转移进入课程详情（详情视图本体由 AXY-17 交付——其演示态 2 含七项字段与先修行；本故事只负责列表行点击的导航）；
- 空态 / 边界：首屏 ≤ 2 秒（AC-1）。

**演示态 2 · 筛选空态**
- 入口：方向选「数据」+ 难度选「高阶」（结果为 0）；
- 布局块：筛选栏（保持当前选择）→ 空态卡「没有符合条件的课程」+「清空筛选」按钮；
- 交互：当用户点「清空筛选」（筛选栏按钮）时，系统恢复 16 门全量、开关与下拉回到全部，以实现筛选可一键重置（AC-4）；
- 空态 / 边界：不出现报错或空白屏。
