**状态**：已批准（DOR 六项自检通过）

## 故事主干

**作为** 想补技能却不知道从哪门学起的本科学生，**我想要** 在课程池里按方向筛出这门赛道上的课程并看清每门的先修与预计时长，**以便** 判断这门课我能不能学、值不值得排进计划。

## 验收标准（AC）

1. **给定** 课程池已导入 16 门课程；**当** 打开课程池；**则** 按 5 个方向分组全量列出，每组首行为组头「方向 · N 门 · 可选 M 门」；每行展示名称、方向、难度、预计时长、章节数、先修数、学习状态；首屏 ≤ 2 秒
2. **给定** 课程池 16 门，方向与难度均为「全部」；**当** 方向选「后端」、难度选「进阶」；**则** 结果 3 门（数据结构与算法基础、计算机网络、数据库原理与 SQL），结果条写「共 3 门 · 后端 · 进阶」，仅保留后端一个分组
3. **给定** 课程池 16 门，方向与难度均为「全部」；**当** 打开「仅看未修习」；**则** 结果 11 门且全部为未开始状态；已完成的 2 门、学习中的 2 门、待复习的 1 门均不出现
4. **给定** 课程池 16 门，方向与难度均为「全部」、开关关闭；**当** 方向选「数据」、难度选「高阶」；**则** 结果 0 门，展示空态「没有符合条件的课程」；点「清空筛选」后恢复 16 门且开关回到关闭
5. **给定** 数据库原理与 SQL 的先修「数据结构与算法基础」为学习中；**当** 查看后端分组；**则** 该课位于后端组分隔条之后（未满足段）、带「先修未完成」标识，组头「可选 3 门」不含它；同段内按难度升序、再按时长升序排列（分布式系统设计排在其后）
6. **给定** 数据库原理与 SQL 的先修「数据结构与算法基础」为学习中；**当** 打开该课详情；**则** 顶部提示先修未完成并列出未满足的课程名，「加入课程规划」不可用且写明需先完成「数据结构与算法基础」
7. **给定** 算法复杂度与基础题训状态为待复习，动态规划专题依赖它；**当** 查看动态规划专题；**则** 该课无「先修未完成」标识、位于算法组可选段内，详情页先修行标「已满足 · 待复习」
8. **给定** 数据结构与算法基础为学习中，数据库原理与 SQL 依赖它并因此带「先修未完成」；**当** 在详情页把该课状态改为「已完成」；**则** 该课显示为「已完成」；返回课程池后数据库原理与 SQL 的「先修未完成」标识消失、从组末移入可选段，后端组头可选数由 3 门变 4 门
9. **给定** 导入批次中有一条课程方向、难度、先修、章节齐全但缺预计时长；**当** 执行导入；**则** 该条被拒并提示缺失字段，池内不出现该课程，课程总数不变
