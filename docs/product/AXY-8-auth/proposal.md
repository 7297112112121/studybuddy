## 2. 目标与背景

刚决定认真学一门课的学生需要一个属于自己的账号，让计划、进度和打卡只认本人，换设备也能接着走（[故事陈述](./story)）。本特性交付账户名注册、账户名+密码登录、会话与路由守卫的完整闭环，是后续全部业务故事（工作台、信息录入等，编号未下发）的前置入口。

## 3. 范围与非目标

### 3.1 范围（做什么）

- 登录路由页（`/login`）：账户名 + 密码，字段级与汇总校验（登录表单无协议勾选行，D-13），登录成功进入工作台承接页。
- 注册路由页（`/register`）：账户名 + 密码 + 确认密码 + 协议勾选（无验证码字段，D-12），注册即登录并进入工作台承接页。
- 会话管理：退出登录、会话失效、已登录访问登录/注册路由页的回退守卫（见路由行为表）。
- 账号数据与安全：密码不可逆摘要、账户名唯一索引（区分大小写）、协议版本与同意时间落库。
- UI 行为与「原型契约」节逐屏一致（登录/注册视图切换、密码可见性、提交中状态）。

### 3.2 非目标（不做什么）

| # | 不做 | 理由 |
| - | ---- | ---- |
| 1 | 短信验证码的发送与校验 | 凭据已改为账户名+密码（D-12），短信验证码无恢复场景；原「通道就绪后另立迭代恢复」计划废止 |
| 2 | 找回密码 | 账户名+密码体系下的找回机制本期未定义，入口不呈现（占位入口已随 D-08 移除） |
| 3 | 第三方登录（微信登录等） | 无对接方，入口不呈现（占位入口已随 D-08 移除） |
| 4 | 邮箱注册与邮箱登录 | D-12：本期唯一凭据形态为账户名；任何邮箱输入按格式非法处理（E-02），不存在邮箱账号 |
| 5 | 《用户协议》《隐私政策》正文内容与法务审阅 | 本期仅落库协议版本与同意时间，协议名为纯文本提及、无链接（D-08） |
| 6 | 2FA、魔术链接、组织等 Better Auth 插件能力 | ADR-0013 约定按需启用，本期不开 |
| 7 | 「记住我」、多端会话管理界面 | 用户故事未涉及 |
| 8 | 企业/高校账号对接 | 线框图品牌区已标注本期不支持 |
| 9 | 新用户信息录入的引导与「跳过」交互 | D-05：建档业务与登录注册业务分离、互不打扰，新用户可录入也可跳过；录入入口的形式归属后续业务故事 |

## 5. 术语与路由

| 术语 | 含义 |
| ---- | ---- |
| 路由页 | 前端路由页面：`/login`（登录）、`/register`（注册） |
| 工作台承接页 | 登录 / 注册成功后的统一落点页（后续工作台故事尚未实现期间的承接，见 D-08、开放问题 #2） |
| 账号 | 数据实体：账户名唯一索引（区分大小写，F-01 / R14）、密码摘要、协议版本与同意时间（见 11.2 领域模型） |
| 会话 | 已登录状态的凭证实体：建立于登录 / 注册成功（R6 / R9），失效于退出（路由行为 #4）或过期；失效后访问受保护路由一律按路由行为 #1 挡回（见 11.2 领域模型） |

### 路由行为表（守卫与跳转的单一事实源）

| # | 触发 | 行为 | 关联 |
| - | ---- | ---- | ---- |
| 1 | 未登录访问任一受保护路由 | 服务端拦截并重定向至 `/login` 路由页；未登录响应不携带受保护页面内容（边界 #6） | R11 |
| 2 | 登录成功 | 进入工作台承接页，不依据建档状态分流（D-03） | R6 |
| 3 | 注册成功 | 自动登录并进入工作台承接页，不强制进入信息录入页（D-04） | R9 |
| 4 | 退出登录 | 回 `/login` 路由页，会话即刻失效（含 Redis 缓存会话）；此后直达工作台承接页地址或浏览器后退均按 #1 挡回；重新登录后原账号与数据完好 | R11 |
| 5 | 已登录访问 `/login` 或 `/register` | 不渲染登录/注册表单；有浏览历史时自动返回上一页；新标签页直接打开（无历史可回退）时进入工作台承接页 | R12 |
| 6 | 页内切换登录 ↔ 注册视图（顶部 tab 与底部链接） | 已填表单值保留、错误提示清除 | R16 |
| 7 | 注册页 E-07 提示中点「去登录」 | 切换到登录视图，且账号框带入该账户名 | R10 |

## 6. 字段与校验规则（F 表）

校验规则的单一事实源；R 条目与原型契约引用 F 编号，不重复正则。

| # | 字段 | 规则 | 违反时 |
| - | ---- | ---- | ---- |
| F-01 | 登录·账户名 | `^[一-龥A-Za-z0-9_]{1,16}$`——中文字符、字母（区分大小写）、数字、下划线，1—16 位；输入框不做字符过滤、提交时校验（D-12） | 留空 → E-01；格式非法 → E-02 |
| F-02 | 密码（登录框、注册框、确认密码框三处规则一致） | 8—20 位且同时含字母与数字（`(?=.*[A-Za-z])(?=.*\d)`） | 违反 → E-03 |
| F-03 | 注册·账户名 | 规则同 F-01；账号表唯一索引（区分大小写） | 非法 → E-02；已注册 → E-07 |
| F-04 | 注册·确认密码 | 与密码一致 | 为空或不一致 → E-05 |
| F-05 | 协议勾选（仅注册表单，D-13） | 必勾（布尔）；勾选与落库（R15）真实生效 | 未勾选提交：表单不提交、勾选框高亮错误态（R4）；错误在勾选框旁呈现、不进汇总计数（D-01） |
| — | 验证码 | 随手机号凭据一并废止（D-12）；本期无验证码字段，亦无恢复计划 | — |

### 11.2 领域模型（四问与双向核对）

四问各成一表，正文引用实体、状态、事件时与本章口径一致；列定义的技术载体以 AXY-8 design 为准，本节只持产品口径。

**概念与状态**

| 实体 | 属性 | 状态 | 状态流转 |
| ---- | ---- | ---- | ---- |
| 账号 | 账户名（唯一索引、区分大小写，F-01 / R14）、密码摘要（R13）、协议版本与同意时间（R15） | 已注册（唯一状态） | 无：注册即以此状态进入（R9）；本产品无账号停用 / 注销流程 |
| 会话 | 所属账号、建立时间、失效原因 | 有效 / 已撤销 / 已过期 | 登录成功（R6）或注册成功自动登录（R9）→ 有效；退出登录 → 已撤销（路由行为 #4，R11）；超过有效期 → 已过期；失效后重新登录建立**新会话**，原账号与数据完好（AC-7） |

**状态义务**（没人须行动的状态不是队列）

| 状态 | 谁须行动 | 义务 | 关联 |
| ---- | ---- | ---- | ---- |
| 会话·已撤销 / 已过期 | 用户 | 重新登录后方可进入受保护路由 | 路由行为 #1 / #4、R11 |
| 已注册账户名再次注册 | 用户 | 按提示转向登录（「去登录」并带入账户名） | 路由行为 #7、R10、E-07 |

**领域事件**

| 事件（领域语言） | 触发 | 结果 | 关联 |
| ---- | ---- | ---- | ---- |
| 账号注册 | 注册表单通过校验提交（F-01 / F-02 / F-04 / F-05）且账户名未被占用 | 账号落库（写入协议版本与同意时间）并自动登录 | R8、R9、R14、R15 |
| 会话建立 | 登录成功或注册成功自动登录 | 进入工作台承接页，受保护路由可达 | R6、R9（路由行为 #2 / #3） |
| 会话撤销 | 退出登录 | 会话即刻失效（含 Redis 缓存会话），回登录路由页 | R11（路由行为 #4） |
| 会话过期 | 超过会话有效期 | 其后访问受保护路由按未登录挡回 | 边界 #5（ADR-0013）、路由行为 #1 |

**负空间**（业务刻意不设的概念——缺失本身是最贵的发现）

| 刻意不设 | 理由 | 依据 |
| ---- | ---- | ---- |
| 邮箱账号 | 邮箱不是账号凭据形态，任何邮箱输入按格式非法处理（E-02） | D-12（非目标 #4） |

| 验证码 | 手机号凭据废止后短信通道无恢复场景 | D-12（非目标 #1） |
| 第三方身份 | 无对接方，入口不呈现 | 非目标 #3（D-08） |
| 角色 / 权限 | 单学生用户产品，当前无任何角色区分 | 提出者 2026-11-16（v3 补全确认） |
| 多端会话管理界面 | 用户故事未涉及 | 非目标 #7 |
| 找回密码 | 账户名+密码体系下的找回机制本期未定义，入口不呈现 | 非目标 #2（D-08） |
| 「已建档」概念 | 登录注册不依据建档状态分流，建档业务归后续业务故事 | D-03 / D-05 |

### 14.2 各演示态契约（可构建级）

**演示态 1 · 登录**
- 入口：未登录访问任意页面重定向至此（路由行为 #1）；
- 布局块：品牌区 → 账户名输入（F-01，输入不过滤字符，D-12）→ 密码输入（F-02，含「显示/隐藏」切换，R17）→「登录」主按钮 →「去注册」链接（路由行为 #6）→ 顶部汇总提示条（登录表单无协议勾选行，D-13）；
- 视觉 / 交互状态：顶部汇总提示按未通过字段项数计数（D-01）；
- 空态 / 边界：账户输入允许任意字符，格式错误仅在提交时呈现（E-02，D-12）；
- 关联 R：R1、R2、R5、R6、R7、R17。

**演示态 2 · 校验失败**
- 入口：登录页触发 R1 / R2 任一校验失败；
- 布局块：与演示态 1 相同，错误提示呈现在对应字段下方，顶部汇总提示条可见；
- 视觉 / 交互状态：错误提示（E-01 / E-02 / E-03）逐字如 E 表；字段值修正为合法值时，对应提示即时消除；
- 空态 / 边界：表单不提交、不跳转；
- 关联 R：R1、R2、R3。

**演示态 3 · 登录中**
- 入口：登录校验通过、请求发出；
- 布局块：与演示态 1 相同，「登录」按钮文案变「登录中…」且置灰不可重复点击（R5）；
- 视觉 / 交互状态：请求成功 → 工作台承接页（R6）；请求失败 → 回演示态 1 并提示 E-06（R7）；
- 空态 / 边界：期间不可重复提交；
- 关联 R：R5、R6、R7。

**演示态 4 · 注册**
- 入口：登录页点「去注册」（路由行为 #6）；
- 布局块：账户名输入（F-03，输入不过滤字符）→ 密码输入（F-02，含「显示/隐藏」切换，R17）→ 确认密码输入（F-04）→ 协议勾选行（F-05；纯文本、无链接，D-08）→「注册并进入」主按钮 →「返回登录」链接；
- 视觉 / 交互状态：协议未勾选时提交被阻断，勾选框高亮为错误态（R4）；
- 空态 / 边界：本期无验证码字段（D-12 废止，非延迟恢复）；
- 关联 R：R3、R4、R8、R9、R10、R17。
