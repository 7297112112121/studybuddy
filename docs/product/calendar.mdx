## 故事主干

**作为** 既要补新课又怕学过的忘光的本科学生，**我想要** 打开一个日历就看到新学与复习两条线铺到每天的任务并直接拖着改期，**以便** 这周临时有事时自己两下就调好，不必为一天的变动重新生成整份计划。

## 验收标准（AC）

| # | 给定 | 当 | 则 |
| - | -- | - | - |
| 1 | 课程规划已排入新学与复习两类任务，2026 年 11 月共 26 项 | 打开日历本 | 默认月视图，按周一起算铺满 6 行 42 格，今天格加「今天」标记；格内每条带类型角标与起止时刻，每格最多 2 条，其余显示「还有 N 项」（11/05 共 3 项即显示「还有 1 项」）；各格条数与「还有 N 项」之和等于 26 |
| 2 | 11/05 有 3 项任务，课程规划为该课设定的时刻为 19:00–19:45、20:30–21:15、21:30–21:50（间隔不等） | 点 11/05 格 | 进入 11/05 日视图，时间轴按三段时刻自上而下排布、间隔如实留白，每块写明起止时刻与分钟数（如 `19:00 – 19:45` 与 45 分钟），块数与月格标注的 3 项一致 |
| 3 | 同一天有多个任务 | 点格内第二条任务条 | 进入日视图并高亮该条任务；其余任务不高亮 |
| 4 | 新学、复习两类均显示中 | 先关「复习」再关「新学」 | 第一次仅剩新学任务，汇总项数与时长同步变为只统计新学；第二次自动恢复为保留至少一类并给出提示，页面不出现空数据 |
| 5 | 11/12 当天没有排任何任务 | 进入 11/12 日视图 | 时间轴照常渲染（19:00–24:00），轴上只放一行「这天没有安排」，不替换成空态卡片，也不隐藏筛选与导航 |
| 6 | 三张计划均为空 | 打开日历本 | 不出现空态页，月格、筛选、汇总照常渲染并显示 0 项，顶部只加一行「还没有任何计划」提示与「去课程规划新建」入口 |
| 7 | 11/06 有一条未开始的新学任务，19:30–20:15 | 拖到 11/09 | 该任务落在 11/09，起止时刻仍为 19:30–20:15 并带「↻」标记；11/06 变空，11/09 原有任务的位置与时刻均不变 |
| 8 | 11/03 19:30–20:15 的新学任务状态为已完成 | 拖到 11/10 | 阻断并提示「已完成任务不可改期」，该任务仍在 11/03，11/10 不新增任务 |
| 9 | 11/06 的任务已于前一步改到 11/09 | 重新生成同一类计划 | 该任务仍在 11/09、带「↻」标记，未被新生成的任务覆盖或移动 |
| 10 | 最早一份计划的开始月为 2026-09 | 翻到 2026-09 后再点「上一个月」 | 按钮不可用并说明最多回溯到最早计划的开始月；点「今天」可直接回到当月 |
