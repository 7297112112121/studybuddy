## 故事主干

**作为** 既要补新课又怕学过的忘光的本科学生，**我想要** 打开一个日历就看到新学与复习两条线铺到每天的任务，**以便** 这周有什么、哪天空着一眼看清（改期操作见 AXY-18〈日历本 · 拖拽改期〉）。

## 目标 / 非目标 / 反目标

- **目标**：打开即见整月任务分布，点入任意一天看清逐段安排。
- **非目标**：拖拽改期（已拆出）；日任务起止时刻二次推算（直接取 AXY-13 写入值，见 DoD）；新学 / 复习各建一套日历数据（共用任务表，见 DoD）。
- **反目标**：用「逐日翻页列表」替代月历总览——即使信息量相同，失去整月扫读即失败。

## 验收标准（AC）

1. **给定** 课程规划已排入新学与复习两类任务，2026 年 11 月共 26 项；**当** 打开日历本；**则** 默认月视图，按周一起算铺满 6 行 42 格，今天格加「今天」标记；格内每条带类型角标与起止时刻，每格最多 2 条，其余显示「还有 N 项」（11/05 共 3 项即显示「还有 1 项」）；各格条数与「还有 N 项」之和等于 26 〔走查：演示态 1〕
2. **给定** 11/05 有 3 项任务，课程规划为该课设定的时刻为 19:00–19:45、20:30–21:15、21:30–21:50（间隔不等）；**当** 点 11/05 格；**则** 进入 11/05 日视图，时间轴按三段时刻自上而下排布、间隔如实留白，每块写明起止时刻与分钟数（如 `19:00 – 19:45` 与 45 分钟），块数与月格标注的 3 项一致 〔走查：演示态 2〕
3. **给定** 同一天有多个任务；**当** 点格内第二条任务条；**则** 进入日视图并高亮该条任务；其余任务不高亮 〔走查：演示态 2〕
4. **给定** 新学、复习两类均显示中；**当** 先关「复习」再关「新学」；**则** 第一次仅剩新学任务，汇总项数与时长同步变为只统计新学；第二次自动恢复为保留至少一类并给出提示，页面不出现空数据 〔走查：演示态 1〕
5. **给定** 11/12 当天没有排任何任务；**当** 进入 11/12 日视图；**则** 时间轴照常渲染（19:00–24:00），轴上只放一行「这天没有安排」，不替换成空态卡片，也不隐藏筛选与导航 〔走查：演示态 3〕
6. **给定** 三张计划均为空；**当** 打开日历本；**则** 不出现空态页，月格、筛选、汇总照常渲染并显示 0 项，顶部只加一行「还没有任何计划」提示与「去课程规划新建」入口 〔走查：演示态 4〕
10. **给定** 最早一份计划的开始月为 2026-09；**当** 翻到 2026-09 后再点「上一个月」；**则** 按钮不可用并说明最多回溯到最早计划的开始月；点「今天」可直接回到当月 〔走查：演示态 1〕

### 各演示态契约

**演示态 1 · 月视图**
- 入口：侧栏「日历本」导航；
- 布局块：月份导航（「上一个月」/「今天」/「下一个月」+ 当前月标题）→ 类型筛选（新学 / 复习开关 + 汇总项数与时长）→ 6 行 42 格月网格（周一起算）；
- 内容与数据形状：种子月 2026-11 共 26 项；格内任务条带类型角标与起止时刻，每格最多 2 条，溢出显示「还有 N 项」；今天格加「今天」标记；
- 交互：点格 → 进入该日日视图（演示态 2）；点格内某条任务 → 日视图并高亮该条（AC-3）；关「复习」→ 只剩新学、汇总同步；再关「新学」→ 自动保留一类并提示，不出现空数据（AC-4）；回溯到 2026-09 后「上一个月」不可用并说明下限，点「今天」回当月（AC-10）；
- 空态 / 边界：条数守恒（各格条数 + 溢出数 = 当月总数，AC-1）；无计划时见演示态 4。

**演示态 2 · 日视图（时刻时间轴）**
- 入口：月视图点格或格内任务条；
- 布局块：返回月视图 + 日期标题 → 时刻时间轴 → 任务块；轴窗口随当日任务伸缩、至少铺满 5 小时，空白天以 19:00–24:00 为基线窗口（沿用已批准的原线框逻辑；AC-2 / AC-5 的种子数据均落在基线窗口内）；
- 内容与数据形状：任务块按写入时刻排布、间隔如实留白，每块写起止时刻与分钟数（如 `19:00 – 19:45` 与 45 分钟），块数与月格标注一致（AC-2）；
- 交互：从格内第二条任务条进入 → 高亮该条、其余不高亮（AC-3）；
- 空态 / 边界：当天无任务时见演示态 3。

**演示态 3 · 无任务的一天**
- 入口：进入没有任何任务的日期（如 11/12）日视图；
- 布局块：时刻轴照常渲染，轴上一行「这天没有安排」；
- 交互：筛选与导航照常可用，不替换空态卡片（AC-5）；
- 空态 / 边界：不隐藏任何功能入口。

**演示态 4 · 无计划（日历照常）**
- 入口：三张计划均为空时打开日历本；
- 布局块：月格、筛选、汇总照常渲染并显示 0 项；顶部一行「还没有任何计划」+「去课程规划新建」入口；
- 交互：点「去课程规划新建」→ 跳转 AXY-13 选课页（AC-6）；
- 空态 / 边界：不出现整页空态。
