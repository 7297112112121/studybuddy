## 故事主干

**作为** 已经把课程排进日历、却每天坐下还要先想「该学哪个」的本科学生，**我想要** 打开一个页面就看见今天要做的几件事并直接在页面上把这一项做完，**以便** 省掉翻计划表的那几分钟，坐下就能开工。

## 验收标准（AC）

| # | 给定 | 当 | 则 |
| - | -- | -- | - |
| 1 | 当天 3 项任务：19:30–20:30 计算机网络、20:40–21:10 数据结构与算法基础（进行中 7/8 题）、21:20–22:05 数据库原理与 SQL | 登录后进入工作台 | 三行按起止时刻升序排列；每行含「新／复」角标、课程、章节、起止时刻、时长、状态与唯一按钮；抬头为「今天 3 项」并报「已完成 0 / 3」，进度条 0% |
| 2 | 同上 3 项，时长分别 60、30、45 分钟 | 查看侧栏「今日 24 小时」 | 轴上三块分别起于 19:30、20:40、21:20，块内标 1/2/3 与轴下三行列表一致；头部报「已安排 2 小时 15 分」，末行报「空闲 21 小时 45 分 · 占全天 9%」，两者相加为 24 小时 |
| 3 | 第二行为「进行中 7/8 题」 | 点该行「继续」 | 该行仍为进行中，执行面板在任务列表下方就地展开，不跳页、不遮住其余两行；页签显示「① 微课文档」「② 刷题打卡 7/8」 |
| 4 | 执行面板停在微课页签 | 查看底部操作区 | 只有「收起」与「去刷题（8 题）」，不出现「完成本任务」；点「去刷题（8 题）」切到刷题页签并停在第 8 / 8 题 |
| 5 | 刷题页签，已完成 7 / 8 题 | 选一个错误选项 | 提示「答错了」并给出解析，已完成题数保持 7 / 8，「完成本任务」仍置灰；改选正确选项后题数变为 8 / 8 并提示「进度 +1 题」 |
| 6 | 刷题页签，已完成 8 / 8 题 | 点「完成本任务」 | 该行变「✓ 已完成」并出现「撤销」，抬头变「已完成 1 / 3」、进度条 33%；若当天仅此一项则抬头走全完成文案 |
| 7 | 三项依次打卡完毕 | 点第一行「撤销」 | 该行回「未开始」、题数清零，抬头与进度条回退为「已完成 2 / 3」与 67%，撤销不加二次确认 |
| 8 | 计划未覆盖到当天 | 打开工作台 | 抬头写「今天没有安排」，列表位置显示「这一天空着」说明卡与「打开日历本」「额外学一章」两个入口；时刻轴不画区块，仅一行「今天没有安排，24 小时都空着」，侧栏其余卡片照常显示 |
| 9 | 日历本把 19:30–20:30 的计算机网络改为 20:00–21:00 | 回到工作台刷新 | 该行起止时刻变为 20:00–21:00，24 小时轴对应块移到 20:00–21:00 位置 |
