# 产品文档

本目录沉淀产品侧的设计产出：用户故事。每篇故事内含**原型契约**——原型的纯文本唯一接口；交互原型不入库，需要看效果时按契约现场生成一次性原型，看完即弃。流程见 [研发流程](../研发流程) 与 product-design 技能。
