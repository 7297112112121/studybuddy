## 故事主干

**作为** 刚决定认真学一门课、还什么都没记录的本科学生，**我想要** 用一个手机号注册出属于我自己的账号，**以便** 计划、进度和打卡只认我一个人，换台设备也能从上次的地方接着走。

## 验收标准（AC）

| # | 给定 | 当 | 则 |
| - | -- | -- | - |
| 1 | 手机号 13800138000 已注册且已建学期档案 | 填入该手机号与正确密码并勾选协议，点「登录」 | 按钮转为「登录中…」且不可重复点击，随后进入「工作台」；同一账号未建档时改为进入 US-01 信息录入页 |
| 2 | 账号框留空、密码填 a1234567 | 点「登录」 | 账号字段下方提示「请输入手机号或邮箱」，顶部汇总提示可见，表单不提交 |
| 3 | 账号填 1380013800（10 位）与 abc@mail（无后缀） | 分别点「登录」 | 两次都提示「格式不对：手机号 11 位，或 name@mail.com」；改填 13800138000 或 name@mail.com 后该提示消失 |
| 4 | 新手机号 13900139000，密码 abcd1234 且两次一致 | 点「注册并进入」 | 注册成功，13900139000 成为该账号的登录手机号，直接进入 US-01 信息录入；用同一号码再注册一次则提示「该手机号已注册，去登录」，不产生第二个账号 |
| 5 | 密码输入框分别填 12345678、abcd1234、abcd12345678901234567 | 逐次提交 | 12345678 与 21 位均提示「密码为 8—20 位，需含字母与数字」，abcd1234 通过校验 |
| 6 | 手机号 13800138000 已注册 | 填入该手机号与错误密码，点「登录」 | 提示「账号或密码不对」，不提示「密码错误」也不提示该号码是否存在；密码框留空时文案一致 |
| 7 | 13800138000 已登录且处于工作台 | 点「退出登录」 | 回到登录页；直接输入工作台地址或浏览器后退均被挡回登录页，重新登录后方可进入；退出后再登录，原账号与数据完好 |
| 8 | 13800138000 已登录且已建学期档案，正处于工作台 | 直接输入 /login 或 /register 访问 | 不出现登录 / 注册表单，自动回退上一页回到工作台；新标签页直接打开（无历史可回退）时改为进入工作台，未建档账号改为进入 US-01 信息录入页 |
