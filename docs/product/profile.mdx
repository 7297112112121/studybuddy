# 用户故事

| 编号 | AXY-11 | 优先级 | P0 | 故事点 | 2 |
| ---- | ---- | ------ | ---- | ------ | ---- |

**状态**：已批准（DOR 六项自检通过）

## 故事主干

**作为** 正在准备求职的本科学生，**我想要** 录入自己的院校、专业、年级、学期、学期开始时间和每学期周数，**以便** 系统按我的真实学籍时间与专业方向换算后续所有安排。

## 验收标准（AC）

1. **给定** 首次进入录入页；**当** 查看六项；**则** 六项均已按默认值填好，无空项，界面无规划相关文案
2. **给定** 六项为默认值；**当** 点击「下一步 · 确认信息」；**则** 确认页六项与录入页逐项一致
3. **给定** 院校或专业被清空；**当** 点击「下一步 · 确认信息」；**则** 停留录入页并提示补填该项，不跳转
4. **给定** 每学期周数当前为 18；**当** 依次输入 40、5、空值；**则** 分别记录为 30 周、12 周、18 周
5. **给定** 六项已确认；**当** 点击「确认，保存信息」；**则** 六项保存成功并提示已保存，界面不出现与规划相关的文案

## 依赖与引用

| 项 | 指向 | 说明 |
| - | ---- | ---- |
| 依赖故事 | 无上游故事 | 注册后可直接进入信息录入，亦可跳过（见 AXY-8 AC-1） |
| 领域模型 | 学籍档案六项：院校、专业、年级、学期、学期开始时间、每学期周数 | 后续规划换算的统一输入 |

## 范围界定

**最小完整交付切片：** 六项默认值齐全（AC-1）→ 必填校验与周数夹逼（AC-3–AC-4）→ 确认页逐项一致（AC-2）→ 保存（AC-5）。

**不纳入范围的内容及原因：**

| # | 不做 | 性质 | 原因 |
| - | ---- | ---- | ---- |
| 1 | 院校库 / 专业库数据建设 | 演示数据（来源待定稿） | 组件内 15 所样本院校与内置专业为演示数据，真实库接口与数据来源待定稿（见开放问题 #1） |
| 2 | 学籍信息后续修改 / 重录流程 | 负空间 | AC 仅覆盖首次录入与确认，修改流程无故事承接 |
| 3 | 规划换算 | 边界 | 六项是规划换算的统一输入，换算本身归课程规划（AXY-13） |
