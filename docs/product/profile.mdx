# 用户故事

| 编号 | AXY-11 | 优先级 | P0 | 故事点 | 2 |
| ---- | ---- | ------ | ---- | ------ | ---- |

**状态**：已批准（DOR 自检通过；2026-11-15 按新模板重写并经 Builder Check 复核）

## 故事主干

**作为** 正在准备求职的本科学生，**我想要** 录入自己的院校、专业、年级、学期、学期开始时间和每学期周数，**以便** 系统按我的真实学籍时间与专业方向换算后续所有安排。

## 目标 / 非目标 / 反目标

- **目标**：首次进入即以默认值完成六项录入并确认保存，系统拿到可换算的学籍输入。
- **非目标**：学籍信息后续修改 / 重录流程（见三桶 ❌）；规划换算（归 AXY-13）；院校 / 专业真实库建设。
- **反目标**：默认值不可用、强迫用户逐项手填才能前进——首次进入的默认值齐全是本故事的存在理由。

## 验收标准（AC）

1. **给定** 首次进入录入页；**当** 查看六项；**则** 六项均已按默认值填好，无空项，界面无规划相关文案 〔走查：演示态 1〕
2. **给定** 六项为默认值；**当** 点击「下一步 · 确认信息」；**则** 确认页六项与录入页逐项一致 〔走查：演示态 2〕
3. **给定** 院校或专业被清空；**当** 点击「下一步 · 确认信息」；**则** 停留录入页并提示补填该项，不跳转 〔走查：演示态 1〕
4. **给定** 每学期周数当前为 18；**当** 依次输入 40、5、空值；**则** 分别记录为 30 周、12 周、18 周 〔走查：演示态 1〕
5. **给定** 六项已确认；**当** 点击「确认，保存信息」；**则** 六项保存成功并提示已保存，界面不出现与规划相关的文案 〔走查：演示态 2〕

### 各演示态契约

**演示态 1 · 录入页**
- 入口：注册成功后可选进入（AXY-8 AC-4）；工作台侧栏暂无「学籍档案」入口（不在任何故事范围，如需要另立故事）；
- 布局块：页标题「学籍信息录入」→ 六项表单（院校、专业、年级、学期、学期开始时间、每学期周数，自上而下）→ 底部主按钮「下一步 · 确认信息」；
- 内容与数据形状：院校（文本 + 候选下拉，演示数据 15 所样本院校）、专业（文本 + 内置候选）、年级（选择器：大一 / 大二 / 大三 / 大四，默认大二）、学期（上 / 下，默认下）、学期开始时间（日期，默认 2027-03-01；清空时保留最近一次有效值）、每学期周数（数字，默认 18，夹逼区间 12–30，失焦纠正并提示「每学期周数按 12—30 周记录」）；六项全部带默认值（默认值与选项集沿用已批准的原线框设计——AI 裁定）；
- 交互：当用户清空院校或专业（文本 + 候选下拉）后点「下一步 · 确认信息」（主按钮）时，系统停留本页并在该字段下方提示补填，以实现六项必填约束（AC-3）；当用户在「每学期周数」（数字输入框）输入 40、输入 5 或清空时，系统按夹逼区间边界钳位（分别纠正为 30、12、回默认 18）并提示「每学期周数按 12—30 周记录」，以实现周数区间约束（AC-4）；当用户六项齐全点「下一步 · 确认信息」（主按钮）时，系统状态转移进入确认页，以实现录入到确认的分步流程（AC-2 前置）；
- 空态 / 边界：首次进入无空项（AC-1）；界面不出现规划相关文案。

**演示态 2 · 确认页**
- 入口：录入页六项齐全后点「下一步 · 确认信息」；
- 布局块：页标题「确认信息」→ 六项只读清单 → 「返回修改」次按钮 + 底部主按钮「确认，保存信息」；
- 内容与数据形状：六项只读值，与录入页逐项一致（AC-2）；
- 交互：当用户点「确认，保存信息」（主按钮）时，系统保存六项并提示已保存，以实现录入结果的落库确认（AC-5）；当用户点「返回修改」（次按钮）时，系统状态转移回录入页且已填值保留，以实现确认前可回改；
- 空态 / 边界：不出现与规划相关的文案。
