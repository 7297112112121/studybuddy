## 故事主干

**作为** 正在准备求职的本科学生，**我想要** 录入自己的院校、专业、年级、学期、学期开始时间和每学期周数，**以便** 系统按我的真实学籍时间与专业方向换算后续所有安排。

## 验收标准（AC）

| # | 给定 | 当 | 则 |
| - | -- | - | - |
| 1 | 首次进入录入页 | 查看六项 | 六项均已按默认值填好，无空项，界面无规划相关文案 |
| 2 | 六项为默认值 | 点击「下一步 · 确认信息」 | 确认页六项与录入页逐项一致 |
| 3 | 院校或专业被清空 | 点击「下一步 · 确认信息」 | 停留录入页并提示补填该项，不跳转 |
| 4 | 每学期周数当前为 18 | 依次输入 40、5、空值 | 分别记录为 30 周、12 周、18 周 |
| 5 | 六项已确认 | 点击「确认，保存信息」 | 六项保存成功并提示已保存，界面不出现与规划相关的文案 |
