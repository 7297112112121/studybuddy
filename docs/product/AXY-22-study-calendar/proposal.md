## 2. 目标与背景

想自己掌控每天安排的本科学生需要一个纯手动记录、想到什么就能随手写上去的个人日程日历,让哪天做什么、当天哪个时间点做什么都是自己亲笔定下的,享受把计划落在本子上的踏实([故事陈述](./story))。这是继 AXY-8 登录注册之后第一个业务故事:日历是后续任务调度、执行采集类故事的地基面;本期它只做「记录的本子」,不做任何 AI 介入(D-03)。

## 3. 范围与非目标

### 3.1 范围(做什么)

- 受保护路由页 `/calendar`(日程日历页):月视图网格 + 当日详情面板(D-01),默认当前月、当日详情选中今天。
- 条目管理:创建(时间可带可不带)、编辑(含修改所属日期,改期走编辑)、删除(二次确认),变更即时生效。
- 边界行为:同一日期时间段可重叠不做冲突校验;过去日期可补记;当日无条目呈现明确空态。
- 数据归属:条目按账号隔离,仅本人可见可改(D-04 之外的一切共享形态均不设)。
- 工作台承接页新增「日程日历」入口链接(D-06)。

### 3.2 非目标(不做什么)

| # | 不做 | 理由 |
| - | ---- | ---- |
| 1 | 重复事件(每周/每日自动出现同一安排) | 纯手动本子原则下重复安排每次手动再记(D-02);将来需要时另立故事 |
| 2 | 到点提醒 / 通知 | 日历本期只承担记录职责,不做闹钟(D-02) |
| 3 | AI 自动排期接入 | AI 调度属产品闭环后续故事,本日历纯手动(D-02 / D-03);对接时另立故事,不改本特性已批准行为 |
| 4 | 共享 / 协作、多日历 / 清单文件夹 | 日历仅本人(条目按账号隔离,D-04 / D-09);负空间登记 |

> 分类 / 标签 / 颜色未获提出者确认排除,不列入本表——见待确认清单 C-01。

| 术语 | 含义 |
| ---- | ---- |
| 日程日历页 | 受保护路由页 `/calendar`:月视图 + 当日详情(D-01) |

## 10. 边界与约束

| # | 边界 | 处理 |
| - | ---- | ---- |
| 1 | 事项文本合法域见 F-01:必填、1—50 字、输入框 50 字硬上限(超限无法继续输入),不做提交时字符过滤(D-07) | 前端与后端双重校验,留空文案见 E-01 |

### 11.2 领域模型(四问与双向核对)

四问各成一表,正文引用实体、状态、事件时与本章口径一致;表结构的技术载体以 AXY-22 design 为准,本节只持产品口径。

**概念与状态**

| 实体 | 属性 | 状态 | 状态流转 |
| ---- | ---- | ---- | ---- |
| 条目 | 归属账号、所属日期(F-04)、事项文本(F-01)、开始时间(F-02,可选)、结束时间(F-03,可选) | 已记录(唯一状态) | 无:创建即存在,删除即消失;无完成 / 取消 / 过期等状态(负空间) |

**状态义务**(没人须行动的状态不是队列)

| 状态 | 谁须行动 | 义务 | 关联 |
| ---- | ---- | ---- | ---- |
| 条目·已记录 | 无人 | 纯记录状态,不构成须行动队列——日历只呈现,不催办(到点提醒为非目标 #2) | 非目标 #2 |

**领域事件**

| 事件(领域语言) | 触发 | 结果 | 关联 |
| ---- | ---- | ---- | ---- |
| 条目创建 | 在所选日期提交合法表单(F-01—F-03,含不带时间的创建) | 条目落库,归属当前账号与所选日期;当日详情与月视图摘要即时更新 | R1、R2、R5 |
| 条目修改 | 编辑提交(含修改所属日期) | 文本 / 时间 / 所属日期更新,原日期与新日期的展示同步变化 | R3、R11 |
| 条目删除 | 二次确认后删除(D-08) | 条目消失、不再展示 | R3 |

**负空间**(业务刻意不设的概念——缺失本身是最贵的发现)

| 刻意不设 | 理由 | 依据 |

| 提醒 / 通知 | 本期不承担闹钟职责 | 非目标 #2(D-02) |

### 14.2 各演示态契约(可构建级)

**演示态 1 · 月视图与当日详情(空态)**
- 入口:登录后从工作台承接页点「日程日历」(路由行为 #2,R10);未登录直达按路由行为 #1 挡回;
- 布局块:页头(标题「日程日历」)→ 月视图网格(默认当前月,每格为日期数字 + 当天条目摘要文字,今日高亮)→ 当日详情面板(标题「M月D日 · 今天」,今日之外的选中天标注实际日期)→ 无条目时空态文案「这天还没有安排」(R6);
- 视觉 / 交互状态:点月视图任意日期格,详情面板切换至该天;今日格常亮标识,选中格与今日格样式可区分;
- 空态 / 边界:选中的天无条目 → 空态文案呈现,不空白、不报错(R6);
- 关联 R:R6、R9、R10。

**演示态 2 · 创建条目(带 / 不带时间)**
- 入口:当日详情面板底部「新建条目」表单区;
- 布局块:事项文本框(F-01,50 字硬上限)→ 开始时间(F-02)→ 结束时间(F-03,开始留空时禁用)→「添加」按钮;
- 视觉 / 交互状态:提交中「添加」置灰、不可重复提交(R12);校验失败在对应字段下方逐字呈现 E-01 / E-03,修正后即时消除;保存失败呈 E-02 且列表不变(R12);
- 空态 / 边界:仅填文本、时间留空直接提交 → 创建不带时间的条目(R2);带开始+结束 → 创建时间段条目(R1);
- 关联 R:R1、R2、R8、R12。

**演示态 3 · 编辑与删除**
- 入口:当日详情中条目行上的「编辑」/「删除」操作;
- 布局块:编辑 → 复用新建表单区(预填原值,含所属日期选择,F-04 / R11);删除 → 轻量二次确认层(确认 / 取消),不在确认层出现额外输入;
- 视觉 / 交互状态:编辑提交即时生效;删除确认后条目从详情与月格摘要同步消失,取消则保留(R3);
- 空态 / 边界:删除当天唯一条目后,该天回到演示态 1 的空态文案;
- 关联 R:R3、R11、R12。

**演示态 4 · 时间重叠并存**
- 入口:同一天已有一条 14:00–15:30 条目,经演示态 2 表单再创建 14:30–15:00;
- 布局块:当日详情两条带时间条目按开始时间先后并列展示;
- 视觉 / 交互状态:全程无冲突提示、无拦截(R4);
- 空态 / 边界:无;
- 关联 R:R4。

**演示态 5 · 过去日期补记**
- 入口:月视图点选过去日期(如昨天)→ 详情面板切至该天 → 经新建表单创建;
- 布局块:与演示态 2 相同,详情标题为所选过去日期(非「今天」);
- 视觉 / 交互状态:创建成功后条目归入所选过去日期,该天月格摘要同步出现(R5);
- 空态 / 边界:无;
- 关联 R:R5。
