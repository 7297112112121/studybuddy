## 按钮

| 状态 | 动画建议 | 时长 |
| --- | --- | --- |
| Hover | 背景加深、轻微上移、阴影增强 | 150ms |
| Active | 缩小到 0.96,阴影减弱 | 100ms |
| Disabled | 透明度降低,无交互反馈 | — |
| Loading | 图标旋转,文字保持或弱化 | 循环 |

主按钮反馈强一些,文字按钮反馈轻一些;加载状态必须停止重复点击。

## 输入框

| 状态 | 动画建议 | 时长 |
| --- | --- | --- |
| Focus | 边框高亮、外发光、标签上浮 | 200ms |
| 输入内容 | 标签缩小并上移 | 200–300ms |
| 错误态 | 红色边框、错误图标淡入 | 200ms |
| 成功态 | 绿色边框、对勾出现 | 200ms |

错误态不夸张抖动;输入过程不频繁触发干扰动画。

## 弹窗

| 部分 | 动画建议 | 时长 |
| --- | --- | --- |
| 背景遮罩 | 淡入 | 250ms |
| 弹窗容器 | 缩放 0.9→1 + 淡入 | 300ms |
| 关闭 | 缩放 1→0.9 + 淡出 | 250ms |
| 内容区 | 延迟 50–100ms 后进入 | 200ms |

遮罩与弹窗同步运动;关闭方向与进入方向一致;内容延迟不超过 100ms。

## 抽屉、侧边栏

| 部分 | 动画建议 | 时长 |
| --- | --- | --- |
| 遮罩 | 淡入 | 250ms |
| 抽屉 | 水平滑入(真实宽度) | 300–400ms |
| 菜单列表 | 依次错位进入 | 每项 50–80ms |
| 关闭 | 反向滑出 + 淡出 | 300ms |

菜单方向符合直觉;列表错位总时长不可过慢;关闭结果可预判。

## 列表

| 场景 | 动画建议 | 时长 |
| --- | --- | --- |
| 新增项 | 淡入 + 向下展开 | 250–350ms |
| 删除项 | 淡出 + 高度收缩 | 250–350ms |
| 列表重排 | 其他项平滑补位 | 300–400ms |
| 批量加载 | 依次进入,错开 50–100ms | 总时长 500ms 内 |

删除和新增必须有动画;重排不跳位;批量加载不逐个太慢。

## Tab 切换

| 部分 | 动画建议 | 时长 |
| --- | --- | --- |
| 下划线 | 平滑移动到当前 Tab | 250ms |
| Tab 内容 | 淡入 + 轻微位移 | 250–350ms |
| 切换方向 | 同层级左右移动或直接淡入 | 200–300ms |

下划线移动比直接切换更有连续感;Tab 多时优先保证滑动性能。

## 导航与菜单

| 组件 | 动画方式 | 时长 |
| --- | --- | --- |
| 下拉菜单 | 展开高度 + 淡入 | 250–350ms |
| 侧边栏 | 水平滑入 + 遮罩 | 300–400ms |
| 面包屑 | 状态高亮变化 | 150–200ms |
| 图标导航 | 图标缩放、颜色变化 | 150–250ms |

当前位置比其他项更突出;动画不影响导航速度。

## 页面切换

| 模式 | 适用场景 |
| --- | --- |
| 淡入切换 | 简单后台、内容页 |
| 左右滑动 | 同层级导航切换 |
| 上下切换 | 详情页展开、模态页 |
| 容器切换 | 同一区域替换内容 |
| 共享元素切换 | 图片、标题、卡片详情(实现成本高,谨慎) |

同层级左右切换,父子级深入/弹出,局部更新容器淡入;不为炫做复杂转场。

## 数据状态

| 状态 | 动画策略 | 设计要点 |
| --- | --- | --- |
| Loading | 骨架屏、进度条、旋转图标 | 稳定、可预测 |
| 加载完成 | 内容淡入、骨架屏退出 | 衔接快 |
| 空状态 | 轻量图标 + 说明文案 | 不过度动画 |
| 错误状态 | 错误图标 + 提示 | 清晰不恐慌 |
| 成功状态 | 对勾、结果提示 | 用于关键操作结果 |
| 数据更新 | 数字变化、图表重绘 | 避免大面积闪烁 |
