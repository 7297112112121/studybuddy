## 位移幅度

| 元素类型 | 建议位移 | 说明 |
| --- | --- | --- |
| 文字、标签 | 4–8px | 轻微上浮即可 |
| 卡片、列表项 | 8–16px | 明显但不过分 |
| 弹窗 | 16–24px | 配合缩放更自然 |
| 侧边栏、Drawer | 等于面板宽度 | 按结构移动 |
| 顶部提示条 | 40–80px | 通常从顶部滑入 |

运动路径保持单轴:抽屉只做水平位移,提示条只做垂直位移,不组合多方向。

## 缩放

| 场景 | 起止比例 | 说明 |
| --- | --- | --- |
| 弹窗进入 | 0.9 → 1 | 轻微缩放,避免夸张 |
| 图片预览 | 1 → 1.02/1.08 | 适合画廊预览 |
| 按钮点击 | 1 → 0.96/0.98 | 按压感 |
| 图标强调 | 1 → 1.1 → 1 | 用于选中或结果反馈 |

## 透明度

| 场景 | 变化 |
| --- | --- |
| 普通淡入/淡出 | 0→1 / 1→0 |
| 辅助元素进入 | 0 → 0.6/0.8 |
| 遮罩出现 | 0 → 0.3–0.6 |
| 禁用态提示 | 0 → 0.4 |

## 缓动曲线

| 曲线 | 适用场景 | 特点 |
| --- | --- | --- |
| ease-out | 进入、弹出、展开 | 开始快结束慢,轻盈 |
| ease-in | 退出、关闭、收起 | 开始慢结束快,利落 |
| ease-in-out | 页面切换、模态框 | 柔和,偏叙事 |
| linear | Loading、进度条 | 匀速,适合循环 |
| cubic-bezier(0.2, 0.8, 0.2, 1) | 现代轻量 UI | 比普通 ease-out 更自然 |
