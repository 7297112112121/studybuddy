# 动画设计规范(motion-design)

## 定位

辅助规范技能:为草稿工作区的组件/布局产出提供动画设计决策与规格,自身不产出条目、不落盘任何文件。动画规格最终落在两个地方:草稿代码的过渡实现(transition/animation 类名与关键帧),与 prompt.md【设计规格】的动画说明。组件与布局的结构产出归 component-* / layout-* 家族技能,本技能只回答「哪些地方该动、怎么动、动多久」。

开发者可直接点名调用(「给这个弹窗设计动画」「列表增删的动效怎么设计」),也可以在家族技能流程中被加载;两条路径的产出纪律一致。

## 硬门禁

1. **无目的不动画**:每个动画先过目的检验——去掉它,用户是否更难理解界面变化?五类正当目标见「设计决策规则」;装饰性动画(纯背景流动、无意义悬浮、自动轮播、大面积渐变流动、频繁闪烁)一律不添加,开发者点名要求时说明风险,开发者坚持再从。
2. **规格必须可执行**:每条动画写全四要素——触发时机、起止状态(具体属性值)、时长(ms)、缓动曲线;禁止「轻微动一下」「自然过渡」类模糊表述。
3. **进入必配退出**:设计进入动画时同步设计退出动画,路径反向,退出时长略短于进入。
4. **性能与可访问性红线**:动画属性只用 `transform` 与 `opacity`,不动画 `width`/`height`/`top`/`left`(高度展开用 `grid-template-rows` 或 max-height 方案时同样在规格中写明,实现仍须避开逐帧布局);必须给出 `prefers-reduced-motion` 下的降级(关闭或简化);状态变化不只靠动画传达,颜色、文字、图标同步变化。
5. **同类同值**:同一产出内同类交互的时长、曲线、位移取值一致,不逐处自定。

## 设计决策规则

### 1. 判断该不该动

五个正当目标,动画至少服务其一;一个都不沾就不加:

| 目标 | 判断信号 |
| --- | --- |
| 建立空间感 | 元素从哪里来:抽屉滑入、弹窗缩放出现、侧边栏展开 |
| 强化因果 | 操作与变化的关联:按下、提交、删除确认 |
| 降低等待感 | Loading、骨架屏、进度、分页切换 |
| 引导注意力 | 新增提示、状态变化、结果反馈 |
| 保持连贯 | 页面、Tab、列表切换的衔接 |

### 2. 选类型

| 界面变化 | 动画类型 |
| --- | --- |
| 按钮、输入框、选项的瞬态 | 微交互 |
| 弹窗、菜单、抽屉的出现消失 | 进入/退出 |
| 页面内容替换 | 页面切换 |
| Loading、空态、结果反馈 | 状态动画 |
| 导航结构变化 | 导航动画 |

### 3. 定时长与曲线

| 规模 | 时长 | 曲线 |
| --- | --- | --- |
| 微交互(Hover / Active / Focus) | 100–200ms | ease-out |
| 小组件(卡片、标签、小面板) | 200–350ms | 进入 ease-out,退出 ease-in |
| 弹窗、抽屉、页面切换 | 300–500ms | ease-in-out |
| 强调反馈(成功、错误) | 400–600ms | 带回弹或分段 |
| Loading、进度 | 循环 | linear |

反馈层级约束:操作后第一层即时反馈 ≤100ms 内可见;第二层操作结果 200–400ms;第三层结构变化 300–500ms。第一层永远最优先——点击后无任何变化是错误设计。

### 4. 逐条设计

按四要素写每条规格。起止状态写具体值,如 `opacity: 0; transform: translateY(12px)` → `opacity: 1; transform: translateY(0)`,位移、缩放、透明度的取值范围与缓动曲线细节按 [references/量化取值.md](references/量化取值.md) 取;做弹窗、抽屉、列表、Tab、按钮、输入框这类组件的动画前,先读 [references/组件动画.md](references/组件动画.md) 对应小节,再逐条写规格。

退出动画通用规则:进入用位移 + 淡入,退出用反向位移 + 淡出;关闭方向与进入方向一致,用户要能预判结束状态。

## 规格表达格式

交付的动画规格一律逐条列表(嵌入 prompt.md 时转为【设计规格】内的动画说明文字):

| 场景 | 触发 | 起止状态 | 时长 | 曲线 |
| --- | --- | --- | --- | --- |
| 弹窗出现 | 打开 | 缩放 0.9→1,淡入 0→1,上移 16px | 300ms | ease-out |
| 弹窗关闭 | 关闭 | 反向:缩放 1→0.9,淡出 | 250ms | ease-in |
| 遮罩 | 随弹窗 | 淡入 0→0.5 | 250ms | ease-out |

`prefers-reduced-motion` 降级单列一行说明,如「reduced-motion:全部过渡改为直接切换」。

## 合理化对照表

| 借口 | 裁决 |
| --- | --- |
| 多动一点显得更精致 | 无目的不动画,装饰性动画一律不加(硬门禁 1) |
| 时长写「快速」「自然」,前端自己把握 | 规格必须可执行,四要素缺一不可(硬门禁 2) |
| 只做进入动画,退出无所谓 | 进入必配退出(硬门禁 3) |
| 用 width/top 做个展开效果 | 只动 transform 与 opacity(硬门禁 4) |
| 这个组件特殊,单独配一套时长 | 同类同值(硬门禁 5) |
