【角色】你是资深前端工程师，技术栈固定为 React + Tailwind CSS + TypeScript。

【任务】生成一个「月历日期选择器」（Month Calendar）组件：紧凑密度单月网格，支持月份翻页、日期选中与事件标记，并完整陈列全部交互状态。
只做该组件本体，不包含页面框架。

【设计规格】

▍整体结构（自上而下三段）
1. 头部行：翻页按钮（上个月）+ 月份标题（YYYY年M月）+ 翻页按钮（下个月），三者整体水平居中，间距 16px；标题 text-sm（14px）font-semibold，颜色 #1A1A2E。
2. 星期表头行：7 列等宽网格，行高 32px，文字「一 二 三 四 五 六 日」text-xs（12px），颜色 #9A9AB0。
3. 日期网格：7 列 × 6 行，行间距 4px；每个日期格为 32px × 32px 全圆角圆形热区，数字 text-sm，水平垂直居中。

▍尺寸与密度（小型 S 档）
- 日期格与翻页按钮高度统一 32px；卡片容器宽 320px、内边距 16px、圆角 12px、边框 1px #EEF0F5。
- 翻页按钮 32px × 32px、圆角 8px，内含 16px 线性箭头图标，颜色 #6B6C85。
- 间距取 8 点栅格：区块间 32px，头内部 16px，网格行间 4px（仅用于极小元素）。

▍色板（锁定，禁止自创色值）
- 主色（选中/今日描边/事件标记）：#5B5BD6
- 文字主色：#1A1A2E
- 文字辅助色：#9A9AB0
- 图标色：#6B6C85
- 悬浮底色：#F3F2FB
- 按压底色：#E9E8F7
- 非本月文字：#D5D6E2
- 边框：#EEF0F5，背景：#FFFFFF

▍状态清单（全量陈列，缺一不可）
日期格七态：
1. 默认：白底，数字 #1A1A2E；
2. 悬浮（Hover）：底色 #F3F2FB；
3. 按压（Active）：底色 #E9E8F7，轻微缩放 0.95；
4. 选中：实心圆 #5B5BD6，白字加粗；
5. 今日：2px #5B5BD6 描边圆，数字 #5B5BD6 加粗；
6. 含事件：数字下方 4px 圆点 #5B5BD6（选中态下圆点转白色）；
7. 禁用（非本月）：数字 #D5D6E2，鼠标 not-allowed，不可点击。
翻页按钮四态：默认 / 悬浮（底色 #F3F2FB）/ 按压（底色 #E9E8F7 + 缩放）/ 禁用（整体不透明度 0.4，边界月场景）。

▍交互说明
- 点击日期即选中（单选），选中态在网格内即时切换；
- 翻页按钮切换上/下个月，标题月份随之更新，跨年自动进位；
- 非本月日期禁用不可点；悬浮/按压反馈时长约 150ms 过渡；
- 可访问性：日期格为 button 并带 aria-label（含「含日程」提示）与 aria-pressed，翻页按钮带 aria-label，网格用 role=grid/gridcell 语义。

【约束】
- 只输出该组件：禁止页面框架、导航、其他组件；
- 状态陈列区必须并排呈现日期格七态与翻页按钮四态，每组配文字标注；
- 不写死业务文案：月份与日期由日期数据驱动，事件标记为通用演示数据；
- 所有色值从上方色板选取，禁止自创；间距遵循 8 点栅格；
- 样式仅用 Tailwind CSS 类表达，不引入组件库依赖。
