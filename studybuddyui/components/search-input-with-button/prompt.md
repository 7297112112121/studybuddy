【角色】你是资深前端工程师，技术栈固定为 React + Tailwind CSS + TypeScript。

【任务】生成一个「带按钮搜索输入框」（Search Input With Button）组件：输入框与主色实心搜索按钮拼接为组合控件，点击按钮或回车触发搜索并进入加载态，加载中禁止重复触发，并完整陈列全部交互状态。
只做该组件本体，不包含页面框架。

【设计规格】

▍整体结构（组合控件，两段拼接无间隙）
1. 输入框段：高 36px（M 档），占剩余宽度，左侧圆角 8px 右侧直角；结构与色板同搜索输入框——前缀 16px 线性放大镜 #9A9AB0（错误态转 #F53F3F）、输入区 text-sm #1A1A2E、占位文字「搜索关键词」#9A9AB0、内边距 12px、元素间距 8px。
2. 搜索按钮段：高 36px 与输入框等高，宽随内容（横向内边距 16px），右侧圆角 8px 左侧直角；实心 #5B5BD6 白字「搜索」text-sm font-medium；按压缩放 0.98。
3. 组合外层：整组圆角 8px，任一元素聚焦时外层出现主色 20% 不透明度 ring 外发光（焦点共享）。
4. 错误提示行：错误态时固定出现在组合控件下方 8px，由 12px 警示圆叹图标 + 错误文字（text-xs #F53F3F）组成。

▍色板（锁定，禁止自创色值）
- 主色 #5B5BD6，按钮 Hover 明度降低约 8% 为 #5151C9，Active 降低约 15% 为 #4747B8；
- 文字主色 #1A1A2E，文字辅助色/图标 #9A9AB0；
- 悬浮边框 #C9CAD8，悬浮底 #FAFAFC，禁用底 #F8F8FB；
- 错误功能色 #F53F3F；清空按钮悬浮底 #F3F2FB / 按压底 #E9E8F7；
- 边框 #EEF0F5，背景 #FFFFFF。

▍状态清单（全量陈列，缺一不可）
输入框六态：默认 / 悬浮（边框 #C9CAD8 + 底 #FAFAFC）/ 聚焦（组合外层主色 ring）/ 有内容（含清空图标）/ 禁用（不透明度 0.4 + not-allowed）/ 错误（边框 #F53F3F + 15% ring + 下方错误提示行）。
搜索按钮五态：
1. 默认：实心 #5B5BD6 白字；
2. 悬浮：#5151C9；
3. 按压：#4747B8 + 缩放 0.98；
4. 禁用：不透明度 0.4，not-allowed；
5. 加载：旋转图标 + 文字「搜索中…」，按钮禁点（aria-busy），加载期间输入框内回车同样不重复触发。
清空按钮三态：默认 / 悬浮（底 #F3F2FB，图标 #1A1A2E）/ 按压（底 #E9E8F7，缩放 0.95），仅悬浮且有内容时显示。

▍交互说明
- 点击按钮或输入框内回车均触发搜索：按钮进入加载态约 1.5 秒，期间按钮与回车均不重复触发；
- 聚焦高亮与外发光约 150ms 过渡；错误态由外部校验驱动，不因输入立即消失；
- 禁用态不响应悬浮与聚焦；
- 可访问性：input 带 aria-label「搜索」，搜索按钮为 button 元素（加载时 aria-busy），清空按钮带 aria-label「清空」，错误提示由图标 + 文字双重呈现。

【约束】
- 只输出该组件：禁止页面框架、导航、其他组件；
- 状态陈列区必须并排呈现输入框六态、搜索按钮五态与清空按钮三态，每组配文字标注；
- 不写死业务文案：占位文字、按钮与错误提示均为通用文案；
- 所有色值从上方色板选取，禁止自创；间距遵循 8 点栅格；
- 样式仅用 Tailwind CSS 类表达，不引入组件库依赖。
