【角色】你是资深前端工程师，技术栈固定为 Next.js (App Router) + Tailwind CSS + shadcn/ui + TypeScript。

【任务】生成一个「聊天伙伴面板」（Chat Panel）组件。
单线 AI 陪伴对话面板：双气泡消息流 + 流式渲染 + 输入区 + 失败重试；全状态陈列，真实可交互。

【设计规格】

1. 面板容器：白色卡片，圆角 12px（rounded-xl），边框 #EEF0F5，阴影 `0 1px 2px rgba(0,0,0,0.05)`，
   内部上下两段：消息列表区（flex-1，overflow-y-auto，内边距 16px，消息间距 16px）+ 输入区（顶部 1px 边框分隔，内边距 12px）。

2. 消息气泡（双气泡式）：
   - 用户消息：右对齐，品牌色 #5B5BD6 实心气泡，白字，圆角 12px（右下角收为 4px），
     内边距横 16px / 纵 8px，字号 14px 行高 24px，最大宽度 70% 容器宽，超长文本自动换行（whitespace-pre-wrap）；
   - 伙伴消息：左对齐，浅灰底 #F3F4F6 气泡，深字 #1A1A2E，圆角 12px（左下角收为 4px），其余同上；
   - 流式渲染：生成中的伙伴消息尾部跟随品牌色竖线光标（宽 8px 高 16px，与文字底部对齐）。

3. 失败重试态：伙伴消息位替换为错误行——浅红底（#F53F3F/5%）+ 红边（#F53F3F/40%）圆角 8px 行，
   内容为警示图标 + 「这条没送达，点一下重试」+ 小号「重试」按钮（红边圆角 6px，悬浮底色 #F53F3F/10%，按压 scale 0.95）。

4. 空态：消息列表为空时居中展示 💬 图标与迎接语「嗨，我是你的学习伙伴，聊点什么？」，辅助色 #9A9AB0。

5. 输入区：
   - textarea：圆角 8px，边框 #D9D9E3，内边距横 16px / 纵 8px，两行高，resize 禁用，
     maxLength 2000；聚焦态边框转 #5B5BD6 + 外圈 #5B5BD6/20% ring（150ms ease-out 过渡）；
     禁用态背景 #F7F7FA + not-allowed 光标；
   - 发送按钮：高 40px 圆角 8px 实心 #5B5BD6 白字 14px medium；Hover 加深至 #4E4EC4（150ms）；
     Active 按压 scale 0.95 并加深至 #4646B4（100ms）；Disabled 整体不透明度 0.4 + not-allowed
     （输入为空或回复生成中时禁用）；
   - 底部提示行：左侧错误文案位（E-01「最多 2000 字，精简一点再发吧」#F53F3F，无错误时透明占位），
     右侧字数计数「N / 2000」#9A9AB0。

6. 动画说明（动画属性仅用 transform 与 opacity）：
   | 场景 | 触发 | 起止状态 | 时长 | 曲线 |
   | 消息进入 | 新消息追加 | opacity 0→1，translateY 12px→0 | 250ms | ease-out |
   | 旧消息退出 | 重试替换 | opacity 1→0 | 200ms | ease-in |
   | 流式光标 | 生成中 | opacity 1→0.2 循环 | 900ms 循环 | linear |
   | 失败反馈 | 回复失败 | 错误行整体淡入 0→1 | 200ms | ease-out |
   | 发送钮按压 | Active | scale 1→0.96 | 100ms | ease-out |
   | Hover 反馈 | 按钮/输入框 | 背景加深 / 边框高亮 | 150ms | ease-out |
   prefers-reduced-motion 降级：全部过渡改为直接切换，光标改为静态竖线。

【约束】
- 不写死业务文案与业务数据：消息内容全部经属性传入，组件脱离具体业务场景后独立成立；
- 状态完整陈列：交互演示（可输入/发送/流式）、生成中、失败重试、空态迎接、超长文本换行、
  交互态标注（默认/Hover/Active/Disabled/聚焦）缺一不可；
- 生成中（流式）时发送钮禁用、输入框占位文案转「伙伴回复中…」，输入框本体可继续打字；
- 样式只用 Tailwind CSS 类，不引入新依赖；支持键盘聚焦与触发（textarea 原生聚焦，按钮可 Tab 到达）；
- 文字超长自动换行、不溢出容器、不产生横向滚动。
