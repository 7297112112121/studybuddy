【角色】你是资深前端工程师，技术栈固定为 React + Tailwind CSS + TypeScript。

【任务】生成一个「日程事件卡片」（Event Card）组件：状态色条型信息卡片，左缘 4px 状态色条区分进行中/已结束，无插图，含时长徽标与双按钮操作行，并完整陈列全部交互状态。
只做该组件本体，不包含页面框架。

【设计规格】

▍整体结构（自上而下三段）
1. 信息行：时间范围（10:00 – 12:00，text-sm，#9A9AB0）居左 + 时长徽标居右（全圆角胶囊，bg #F3F2FB，文字 30 分钟 text-xs font-medium #5B5BD6，内含 14px 时钟线性图标，图标与文字间距 8px）。
2. 标题行：事件标题 text-base（16px）font-semibold #1A1A2E，最多两行，超出以省略号截断（line-clamp-2）；标题右侧为状态徽标（进行中：bg #F0EDFC 文字 #5B5BD6；已结束：bg #F4F4F8 文字 #9A9AB0；默认态无徽标），徽标 whitespace-nowrap 不换行。
3. 操作行：次按钮（稍后处理，bg #F3F2FB 文字 #5B5BD6）+ 主按钮（查看详情，实心 #5B5BD6 白字），高度均 36px（M 档）、圆角 8px、横向内边距 16px，按钮间距 12px；一个卡片内主按钮仅一个。

▍状态色条
- 卡片左缘 4px 全高色条：默认/进行中为 #5B5BD6，已结束为 #D5D6E2；
- 状态区分不只靠颜色：色条必须搭配文字徽标同时呈现。

▍卡片容器
- 宽 320px，圆角 12px，边框 1px #EEF0F5，内边距 24px（左内边距含色条区共 28px）；
- 阴影分层：静止态 0 1px 2px rgba(0,0,0,0.05)；悬浮态 0 2px 8px rgba(0,0,0,0.08) 并上移 2px。

▍色板（锁定，禁止自创色值）
- 主色：#5B5BD6，Hover 明度降低约 8% 为 #5151C9，Active 降低约 15% 为 #4747B8
- 文字主色：#1A1A2E，文字辅助色：#9A9AB0，已结束弱化文字：#C2C3D2
- 次按钮底：#F3F2FB，按压底：#E9E8F7 / #DCDBF2
- 非功能灰：#D5D6E2，边框：#EEF0F5，背景：#FFFFFF

▍状态清单（全量陈列，缺一不可）
卡片五态：默认 / 悬浮（阴影加深 + 上移）/ 进行中（紫条 + 徽标）/ 已结束（灰条 + 时间与标题弱化）/ 长标题截断（两行省略）。
主按钮五态：默认 / 悬浮（#5151C9）/ 按压（#4747B8 + 缩放 0.98）/ 禁用（不透明度 0.4 + not-allowed）/ 加载（旋转图标 + 文字「处理中」+ 禁止重复点击）。
次按钮四态：默认 / 悬浮（#E9E8F7）/ 按压（#DCDBF2 + 缩放）/ 禁用（不透明度 0.4）。

▍交互说明
- 可点击卡片悬浮时阴影加深并轻微上移，约 150ms 过渡；按钮点击有 0.98 缩放按压反馈；
- 加载态按钮禁用点击且带 aria-busy；禁用态按钮不响应悬浮；
- 可访问性：卡片为 article 语义，状态徽标为文字呈现（色弱可辨），按钮均为 button 元素。

【约束】
- 只输出该组件：禁止页面框架、导航、其他组件；
- 状态陈列区必须并排呈现卡片五态、主按钮五态、次按钮四态，每组配文字标注；
- 不写死业务文案：标题用通用占位文本，时间与时长为通用演示数据；
- 所有色值从上方色板选取，禁止自创；间距遵循 8 点栅格；
- 样式仅用 Tailwind CSS 类表达，不引入组件库依赖。
