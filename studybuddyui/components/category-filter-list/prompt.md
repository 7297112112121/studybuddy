【角色】你是资深前端工程师，技术栈固定为 React + Tailwind CSS + TypeScript。

【任务】生成一个「分类筛选列表」（Category Filter List）组件：标题行（列表名 + 圆形新增按钮）+ 复合行列表，每行为彩色勾选框 + 分类名 + 进度条，支持勾选筛选与逐项禁用，并完整陈列全部交互状态。
只做该组件本体，不包含页面框架。

【设计规格】

▍整体结构（自上而下三段）
1. 标题行：列表名（text-base 16px font-semibold #1A1A2E）居左 + 新增按钮居右；按钮 32px × 32px 全圆角，1px 边框 #EEF0F5，内含 16px 加号线性图标 #6B6C85。
2. 复合行：行高 40px（M 档），横向内边距 8px，内部间距 12px，三段从左到右——
   · 勾选框：20px × 20px，圆角 4px；选中为分类色实心底 + 白色对勾图标，未选为白底 2px 分类色描边；
   · 分类名：text-sm #1A1A2E，未勾选时弱化为 #9A9AB0；
   · 进度条：占行内剩余宽度，高 4px，轨道 #EEF0F5 圆角全圆，填充为分类色，宽度即进度百分比。
3. 空列表态：标题行保留，列表区为虚线边框占位块（1px dashed #D5D6E2，高 80px），居中提示文字 text-sm #9A9AB0。

▍分类色板（锁定，禁止自创色值）
- 分类色三档：紫 #5B5BD6、青 #19B5A9、橙 #F2994A；勾选框与进度条同色呼应；
- 文字主色 #1A1A2E，文字辅助色 #9A9AB0，禁用灰 #D5D6E2；
- 行悬浮底 #F8F8FB，按压底 #F3F2FB，边框 #EEF0F5，背景 #FFFFFF。

▍状态清单（全量陈列，缺一不可）
行五态：
1. 默认（勾选）：白底，勾选框实心 + 进度条分类色；
2. 悬浮：行底色 #F8F8FB；
3. 勾选：实心勾选框，文字主色；
4. 未勾选：描边勾选框，文字弱化，进度条保留进度；
5. 禁用：整体不透明度 0.6，勾选框不可点（not-allowed），进度条填充转 #D5D6E2。
新增按钮四态：默认 / 悬浮（底色 #F3F2FB）/ 按压（底色 #E9E8F7 + 缩放 0.95）/ 禁用（不透明度 0.4）。
列表扩展态：空列表（虚线占位 + 引导文案）。

▍交互说明
- 勾选框点击即切换选中态（多选），行内即时更新；勾选语义为「筛选是否启用」，与进度条（分类完成度）相互独立；
- 行悬浮有底色反馈，约 150ms 过渡；新增按钮带悬浮/按压反馈；
- 可访问性：勾选框为 button + role=checkbox + aria-checked，进度条带 role=progressbar 与 aria-valuenow/valuemin/valuemax，新增按钮带 aria-label。

【约束】
- 只输出该组件：禁止页面框架、导航、其他组件；
- 状态陈列区必须并排呈现行五态、新增按钮四态与空列表态，每组配文字标注；
- 不写死业务文案：分类名用「分类项」占位，进度为通用演示数据；
- 所有色值从上方色板选取，禁止自创；间距遵循 8 点栅格；
- 样式仅用 Tailwind CSS 类表达，不引入组件库依赖。
