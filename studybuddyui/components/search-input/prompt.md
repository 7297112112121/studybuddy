【角色】你是资深前端工程师，技术栈固定为 React + Tailwind CSS + TypeScript。

【任务】生成一个「搜索输入框」（Search Input）组件：图标前置 + 内嵌清空按钮的单行紧凑输入框，无标签区，支持聚焦高亮与错误反馈，并完整陈列全部交互状态。
只做该组件本体，不包含页面框架。

【设计规格】

▍整体结构（单段）
1. 输入框容器：高 36px（M 档），宽 320px，圆角 8px，边框 1px #EEF0F5，横向内边距 12px；内部水平排布三元素，间距 8px——
   · 前缀搜索图标：16px 线性放大镜，颜色 #9A9AB0；
   · 输入区：占满剩余宽度，text-sm #1A1A2E，占位文字「搜索关键词」#9A9AB0；
   · 后缀清空按钮：14px 线性叉号，仅在输入框悬浮且有内容时显示（交互实现为 opacity 0 → group-hover 1）。
2. 错误提示行：错误态时固定出现在输入框下方 8px，由 12px 警示圆叹图标 + 错误文字（text-xs #F53F3F）组成。

▍色板（锁定，禁止自创色值）
- 主色（聚焦边框/外发光）：#5B5BD6，外发光为主色 20% 不透明度 ring；
- 文字主色：#1A1A2E，文字辅助色/图标：#9A9AB0；
- 悬浮边框：#C9CAD8，悬浮底：#FAFAFC；
- 错误功能色：#F53F3F，错误外发光为 15% 不透明度 ring；
- 边框 #EEF0F5，禁用底 #F8F8FB，清空按钮悬浮底 #F3F2FB / 按压底 #E9E8F7，背景 #FFFFFF。

▍状态清单（全量陈列，缺一不可）
输入框六态：
1. 默认：白底，边框 #EEF0F5；
2. 悬浮（Hover）：边框 #C9CAD8，底色 #FAFAFC；
3. 聚焦（Focus）：边框 #5B5BD6 + 主色 20% ring 外发光；
4. 有内容：显示文字与清空图标；
5. 禁用：底色 #F8F8FB，整体不透明度 0.4，鼠标 not-allowed；
6. 错误：边框 #F53F3F + 15% ring，前缀图标转 #F53F3F，下方错误提示行（红边框 + 错误文字 + 警示图标三重反馈）。
清空按钮三态：默认（#9A9AB0）/ 悬浮（底 #F3F2FB，图标 #1A1A2E）/ 按压（底 #E9E8F7，缩放 0.95）。

▍交互说明
- 聚焦时边框高亮 + 轻微外发光，约 150ms 过渡；错误态不因输入立即消失，由外部校验驱动；
- 清空按钮点击即清空内容并保持聚焦；仅悬浮/聚焦且有内容时可见；
- 禁用态不响应悬浮与聚焦；
- 可访问性：input 带 aria-label「搜索」，清空按钮带 aria-label「清空」，错误提示行由图标 + 文字双重呈现（不只靠颜色）。

【约束】
- 只输出该组件：禁止页面框架、导航、其他组件；
- 状态陈列区必须并排呈现输入框六态与清空按钮三态，每组配文字标注；
- 不写死业务文案：占位文字与错误提示均为通用文案；
- 所有色值从上方色板选取，禁止自创；间距遵循 8 点栅格；
- 样式仅用 Tailwind CSS 类表达，不引入组件库依赖。
