【角色】你是资深前端工程师，技术栈固定为 Next.js (App Router) + Tailwind CSS + shadcn/ui + TypeScript。

【任务】生成一个「日程页栅格布局」（Calendar Grid Layout）骨架。
只输出布局结构，不生成任何具体组件。

【设计规格】
1. 根容器纯白背景，占满视口高度（min-h-[720px]）；页面内容收拢在一个 12 列栅格中取 8 列（约 67% 视口宽）的居中容器内，
   容器顶部内边距 24px、底部留白 96px（卡片不顶满屏，下方保留背景留白）。
2. 容器内部自上而下两段，均与容器左右缘对齐：
   - 头部行：高 56px（简约风格顶栏标准），同一行内两个区域两端对齐（justify-between）、顶边共线：
     · 1 页面标题区：宽 2 列（容器的 25%）灰盒（#D9D9D9），白字「1、页面标题区」居中，承载页面标题「日程日历」；
     · 2 工具栏区：宽 3 列（容器的 37.5%）灰盒，白字「2、工具栏区」居中，
       承载视图切换（周/月）、前后翻页与「今天」按钮；标题区与工具栏区之间为中段留白。
   - 3 周视图卡片：位于头部行下方 24px，占容器余高的大灰盒，白字「3、周视图卡片」居中，
     承载星期表头行（含全天行）与左侧时间轴的 7 列周时间网格（当前时间红线），骨架阶段以单盒表达。
3. 栅格基准：区域宽度均为 12 列栅格的整数列（容器 8 列、标题 2 列、工具栏 3 列）；间距遵循 8 点栅格
   （24/56/96px）。

【约束】
- 只输出布局骨架：灰色盒子（#D9D9D9）+ 白字标注（编号、区域名），禁止具体组件、图标、真实文案、阴影装饰。
- 背景统一纯白；区域宽度不得偏离整数列取值。
- 视图切换控件、星期表头、时间轴与网格线等具体内容一律不生成。
