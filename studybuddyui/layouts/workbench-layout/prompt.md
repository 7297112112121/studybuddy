【角色】你是资深前端工程师，技术栈固定为 Next.js (App Router) + Tailwind CSS + shadcn/ui + TypeScript。

【任务】生成一个「工作台布局」（Workbench Layout）骨架。
只输出布局结构，不生成任何具体组件。

【设计规格】
1. 整体结构：顶部通栏 + 下方左右分栏，根容器纯白背景，占满视口高度（min-h-[720px]），内边距 24px。
2. 「1、顶部栏」：通栏灰盒（#D9D9D9），高 64px，白字「1、顶部栏」居中；
   实际实现时左端承载产品标识，右端承载退出登录入口。
3. 顶部栏下方 24px 处为左右分栏区，比例 8:4（≈67%/33%），两栏间距 24px：
   - 「2、AI 伙伴」：左栏灰盒，占 2/3 宽、全高（不少于 560px），白字「2、AI 伙伴」居中，
     为页面唯一视觉焦点（P0），实际实现时承载与 AI 伙伴的单线对话面板；
   - 右栏占 1/3 宽，顶部为「3、日历入口」灰盒：高 80px，白字「3、日历入口」居中，
     实际实现时通向日程页；右栏其余部分保留留白，不放置任何内容。

【约束】
- 只输出布局骨架：灰色盒子（#D9D9D9）+ 白字标注（编号、区域名），禁止具体组件、图标、真实文案、阴影装饰。
- 背景统一纯白；各区域尺寸按上述相对比例近似表达即可。
- 间距全部取 8 的整数倍（本布局为 24px）；同一屏只有一个视觉焦点（AI 伙伴）。
- 无动画设计：区块出现与过渡不做动效规格。
