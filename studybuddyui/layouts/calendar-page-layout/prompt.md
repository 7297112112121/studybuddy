【角色】你是资深前端工程师，技术栈固定为 Next.js (App Router) + Tailwind CSS + shadcn/ui + TypeScript。

【任务】生成一个「日程页布局」（Calendar Page Layout）骨架。
只输出布局结构，不生成任何具体组件。

【设计规格】
1. 根容器纯白背景，占满视口高度（min-h-[720px]）；页面内容整体收拢在一个限宽约视口 54% 的居中容器内，
   容器顶部内边距 24px、底部留白约 96px（卡片不顶满屏，下方保留背景留白）。
2. 容器内部自上而下三段，均与容器左缘对齐：
   - 1 页面标题区：高 48px、宽约容器 15%（min-w-[120px]）灰盒（#D9D9D9），白字「1、页面标题区」居中，
     承载页面标题「日程日历」；
   - 2 工具栏区：位于标题区下方 16px，高 40px、宽约容器 25%（min-w-[200px]）灰盒，白字「2、工具栏区」居中，
     承载视图切换（周/月）、前后翻页与「今天」按钮；
   - 3 周视图卡片：位于工具栏区下方 16px，占容器余高的大灰盒，白字「3、周视图卡片」居中，
     承载星期表头行（含全天行）与左侧时间轴的 7 列周时间网格（当前时间红线），骨架阶段以单盒表达。

【约束】
- 只输出布局骨架：灰色盒子（#D9D9D9）+ 白字标注（编号、区域名），禁止具体组件、图标、真实文案、阴影装饰。
- 背景统一纯白；各区域尺寸按上述相对比例近似表达即可。
- 视图切换控件、星期表头、时间轴与网格线等具体内容一律不生成。
