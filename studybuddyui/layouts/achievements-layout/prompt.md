【角色】你是资深前端工程师，技术栈固定为 Next.js (App Router) + Tailwind CSS + shadcn/ui + TypeScript。

【任务】生成一个「成就展示页布局」（Achievements Layout）骨架。
只输出布局结构，不生成任何具体组件。

【设计规格】
1. 整体双栏结构，根容器纯白背景，占满视口高度（min-h-[720px]）：
   - 左侧「1、分类侧栏」：固定宽约视口 20%，全高；
   - 右侧「2、主内容区」：占余宽，内边距 32px，内部上下两段、间距 32px。
2. 分类侧栏承载成就类别导航（全部/学习/连续打卡/社交/挑战）；
   布局骨架阶段以单个灰盒（#D9D9D9）表达，白字「1、分类侧栏」居中。
3. 主内容区两段：
   - 2.1 统计横幅：通栏灰盒，高 96px，白字「2.1、统计横幅」居中，承载成就总览统计（如「12/48 已解锁」）；
   - 2.2 徽章网格区：占主区剩余全部高度的大灰盒，白字「2.2、徽章网格区」居中，
     内容为 4 列等宽徽章卡片网格（已获得/进行中/未解锁三类徽章），骨架阶段以单盒表达。

【约束】
- 只输出布局骨架：灰色盒子（#D9D9D9）+ 白字标注（编号、区域名），禁止具体组件、图标、真实文案、阴影装饰。
- 背景统一纯白；各区域尺寸按上述相对比例近似表达即可。
- 侧栏导航项、统计数字、徽章卡片等具体内容一律不生成。
