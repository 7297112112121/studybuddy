【角色】你是资深前端工程师，技术栈固定为 Next.js (App Router) + Tailwind CSS + shadcn/ui + TypeScript。

【任务】生成一个「聊天页布局」（Chat Page Layout）骨架。
只输出布局结构，不生成任何具体组件。

【设计规格】
1. 整体双栏结构，根容器纯白背景，占满视口高度（min-h-[720px]）：
   - 左侧「1、侧边栏」：固定宽约视口 12%（min-w-[220px]），全高；
   - 右侧「2、主内容区」：占余宽。
2. 侧边栏区域承载 logo 行、「开启新对话」按钮、按时间分组的会话列表与底部用户信息行；
   布局骨架阶段以单个灰盒（#D9D9D9）表达，白字「1、侧边栏」居中。
3. 主内容区垂直居中略偏上（中轴上移约 24px），内部上下两段、水平居中：
   - 2.1 欢迎标题区：宽约主区 30%，高 64px 灰盒，白字「2.1、欢迎标题区」，承载欢迎语标题；
   - 2.2 输入卡片区：位于标题区下方约 32px，宽约主区 51%，高 176px 灰盒，白字「2.2、输入卡片区」，
     承载消息输入卡片（含功能胶囊与发送按钮）。

【约束】
- 只输出布局骨架：灰色盒子（#D9D9D9）+ 白字标注（编号、区域名），禁止具体组件、图标、真实文案、阴影装饰。
- 背景统一纯白；各区域尺寸按上述相对比例近似表达即可。
- 侧栏内部结构、输入框与按钮等具体内容一律不生成。
